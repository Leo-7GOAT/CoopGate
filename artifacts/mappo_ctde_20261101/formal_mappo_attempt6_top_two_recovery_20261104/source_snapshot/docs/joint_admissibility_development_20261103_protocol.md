attempts 4 or 5 and not a statistical certificate. No new alpha is allocated.
It retains all three genuine MAPPO actors (4703/4704/4705), the common physical
baseline, complete finite forecast bank, 0.0025 gain floor, and per-car tests.
Strict continuous crossing-phase and fitted-history checks move inside candidate
search. A rejected candidate no longer discards all remaining legal candidates.
Historical registered sources and all original data remain byte unchanged.

For one fixed observation/history, order candidates as before. Let P(c) be the
original bank and physical predicates; let Q(c) be strict phase plus observed
history predicates. The old algorithm tests Q only on first c satisfying P.
The new algorithm selects the first c satisfying P and Q. Thus any old accepted
command is unchanged at the SAME history. If that first command fails Q, an
alternative may be accepted. This is a per-decision search inclusion statement;
it is NOT a closed-loop performance or risk guarantee because later histories
can diverge. The existing fitted constant innovation remains a forecast
hypothesis, not a posterior or a guarantee of future disturbance coverage.

(all scene/plant/disturbance combinations, seeds 879000001 onward) PLUS EVERY
unique adverse initial in the completed attempt4 and powered attempt5 diagnosis.
