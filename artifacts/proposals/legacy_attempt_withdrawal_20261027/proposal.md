# 旧前置试验停用提案（尚未启用）

本提案不改变三个研究目标。当前脚本、进程、冻结计划和统计判定均保持原状，必须经用户明确授权后才能改动执行前置条件。

## 两种执行路径

| 项目 | 保持现有流程 | 拟议提速路径 |
|---|---|---|
| 旧校准 | 补齐剩余 60,095 次运行，再完成 204,800 次完整复核 | 保留现有 144,705 条记录，声明该旧尝试未完成、未取得证书 |
| 旧确认 | 校准完成后执行 92,160 次，再完整复核 | 不再启动此旧阶段 |
| 新联合风险试验 | 旧试验完整结束后执行 | 当前 OOD 复核完成后优先执行 |
| 新试验样本量 | 3,072 校准初始条件 + 1,024 确认初始条件，共 16,384 次运行 | 完全相同，不减量、不替换 |
| 其他对照、场景和因子实验 | 全部执行 | 全部保留 |

这是停用旧的阻塞前置试验，不是把新联合风险验证改成小样本实验。按提案创建时的状态，可避免旧流程中仍待执行的 152,255 次仿真及相应复核；没有把它们算作完成。

## 统计边界

旧尝试分配的错误预算为 0.025；新联合风险尝试的预算为 0.05/6。两套预算分别保留，旧额度不转移、不重新使用，也不声称两套不同检验族共同具有某个未经证明的整体错误率。

新试验的 4,096 个初始条件种子与旧预检查、校准和确认的全部种子无交集。三个固定模型、门控阈值、场景抽样、动力学、风险上限、采用率下限、收益下限、失败保留和完整复核要求全部保持原定数值。

令 W 为仅依据资源和执行进度、在读取旧试验部分效应前作出的停用决定，D2 为原定且独立的新试验数据。固定候选和判定规则不因 W 改变时，若原检验在所用模型假设下具有有限样本水平 alpha2，新试验错误部署事件 E 仍满足 P(E | W) ≤ alpha2，因而 P(E 且 W) ≤ alpha2·P(W) ≤ alpha2。对于仅在有限方差条件下渐近有效的均值推断，只能作相应的渐近陈述，不能把上述不等式解释为其有限样本保证。该论证只说明资源性停用不额外增加新试验的检验预算；不保证实验会通过。种子不交集是避免复用的检查，统计独立性仍依赖原抽样设计，不能仅由种子数值不同推出。

停用旧尝试不产生旧试验的成功声明、p 值或证书，也不允许读取部分效应来挑模型、调阈值或决定后续样本。

## 授权后的执行要求

1. 保留原冻结文件和全部旧数据；如旧工作进程已开始，只能先核对其精确进程身份并保留中断记录，不能伪造零退出。
2. 把旧尝试标为“因资源优先级停用，未获得证书”。
3. 在新试验任何绑定或采集前，冻结并提交仅变更前置执行条件的修订；校验新样本表、模型、统计契约的指纹与本提案相符。
4. 当前 OOD 完整复核、16,384 次新联合风险运行、公平对照、候选因子实验及 CSPI 分析继续全部执行。

原计划明确包含 `"previous_attempt_terminal_required": true`，其执行器进一步要求旧校准和旧确认完整结束。因此这是需要明确决定的冻结协议变更，不能当作普通代码加速悄悄启用。

机器可核对的计划指纹、种子不交集结果与两套错误预算见同目录 proposal.json。
