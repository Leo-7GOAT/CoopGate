# 实际 SUMO 中的策略故障接管

完成 384 次实际 SUMO 运行：八个独立初态、四类扰动、单车与多车两套学习策略、六种运行分支。两套策略分别是冻结的 V14 单车网络 901 和 V16 第一轮完整三 actor 模型；各自退回强自车规划或强协同规划。

|运行分支|单车套件回合|多车套件回合|
|---|---:|---:|
|直接运行传统基线|32|32|
|强制采用学习，无故障|32|32|
|策略执行抛出异常|32|32|
|策略输出 NaN|32|32|
|策略输出越界指令|32|32|
|初始拒绝学习，运行基线|32|32|

192 个故障回合在预定第 4 或第 8 个决策周期注入故障，均在车辆到达前。接管从当时实测状态与上一条实际指令开始，在本次合流内保持基线接管，不重新初始化为零指令，也不把此前的学习执行从轨迹中删掉。

所有 384 回合完成，无记录碰撞、中止或物理契约违规。逐步复核了 4,898 条接管/拒绝后的基线指令，与实际执行一致；初始拒绝学习的 64 条轨迹也与相同初态、扰动下直接执行基线的轨迹一致。全部轨迹按各车自己的到达时刻重新计算成本并复核物理子步。

为专门检验恢复能力，此实验**人为设定是否准入学习**，没有使用统计置信度。它不证明门控能正确筛选有益学习策略，也不能把故障接管解释为相对“一开始就运行基线”的性能非退化。故障回合保留原始准入标签，不能从有害采用率的分母中移除。

物理结论仍限于本项目的固定路线、精确状态、三辆受控车辆、已知动力学和加速度误差界。没有测量通信延迟或进行实车试验。
