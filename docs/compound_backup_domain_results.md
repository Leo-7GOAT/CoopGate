# 完整前缀诊断：复合模型下的全车制动尚不能初始化原任务

新增开发组件通过 17 项检查，包含独立动力学的参数角点/随机回放、三种隐藏延迟、
终端后最坏正创新、队列遗留正指令、区间几何与中点反例，以及备份后缀管理。
这表明实现具有可核查的条件逻辑；不表示已解决原仿真任务。

在提交源代码、完整范围和判据之后，对已完成 117 条 SUMO 轨迹的**全部 2,245 个
公共接收前缀**进行诊断，包括全部 39 个中止观测。诊断程序实际退出码为 0。
没有新增 SUMO、控制动作、学习训练或独立初态，没有读取运行中的正式实验效果。

核心结果：**仅 21/2,245 帧通过，全体 117 条记录的初始帧均未通过，39 个中止帧
均未通过。** 这些记录复用三个旧初态，117 与 2,245 都不是独立样本量，不生成
总体风险置信区间或显著性结论。

不能成为预处理方法的安全排名。

## 检查回答的问题

每个前缀仅使用当前观测、来源时间戳、公共模型边界与过去已执行指令。先独立重算
状态/记忆盒并核对父日志，随后检查当前最强合法制动指令、后续按 jerk 限制降至
最大制动的固定策略族。延迟为 1–3 个决策周期，模型范围覆盖公开的复合增益、
阻力、惯性与有界创新。每一物理步检查固定三车路线的盒几何，终端还要求零速、
足够负的执行器记忆，以及所有未排空 FIFO 指令与永久保持指令均满足制动条件。

全部 2,224 个拒绝均返回 `route_box_not_certified`；这表示所传播的外包络未通过
几何充分检查，**不是测得真实碰撞**。它也不能区分：所有车辆同时制动的策略族
不足、宽模型范围及盒传播丢失相关性造成的保守拒绝、或者真实物理限制。
不能据此宣称这些初态不可恢复，也不能删除初始拒绝记录以改善通过率。

尤其是干净父轨迹本来完成了任务，新检查仍拒绝其初始制动方案，说明“原任务能
完成”和“在更宽模型类下能证明全车制动安全”是不同命题。新组件没有提供优于
旧控制器的任务完成证据。

## 对下一步实现的约束

现有 `RetainedBrakePlan` 能在新候选拒绝时保留旧制动后缀、核对执行确认并保持
终端指令。但这里没有初始证书，因此该管理器目前无法在这些原初态上初始化。
**不把新模块接入原任务并命名为已修复的安全回退控制器。**

下一步需要分离检查具有通行优先次序的协调恢复策略与相关性更强的可达集合表示，
保留原初态和全部失败；若采用更小可恢复域，只能作为另一个显式范围，不得替代
原始完整任务。后续仍须有真正执行恢复序列的原生闭环与独立审计，才可讨论物理
停车效果。当前条件性实数证明与 float64 余量不构成经验证的浮点区间程序。

正式收益/采用率/性能风险验收、公平对照与完整 OOD 队列不因此改变。此诊断不能
生成新的性能风险证书，不能用通过帧子集报告完整收益，也不构成 MARL 改进。
