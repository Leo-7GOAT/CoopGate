# 原版 DMPS 的真实 SUMO 状态恢复接入

本阶段只验证原 mcts.py 在真实 SUMO 环境的接口，不声称完成 DMPS 训练或公平性能
比较。原文件固定提交 f37df2d3900cfdc330ebb39e9b89d05dd9b85a7e、Git blob
68a83a6eaf518cc4ed7d2f07ccf7cd7f7ccc686c，不修改其函数体。

桥接真实 MatchedShiftedMergeEnv。私有 reset 依赖绑定仅追加 SUMO 状态保存精度 17
和 RNG 保存选项，原冻结源代码及全局绑定不变。状态快照同时包含原生 SUMO XML、
Python 回合字段、轨迹、前一命令、执行器记忆、扰动数组与游标以及动作采样器 RNG。
快照只能载入同一仿真器的同一 reset 代；加载后核对原生运动状态和 SUMO 时钟。
规划器自己的 NumPy 搜索 RNG 不回滚，否则会错误重复搜索候选。

三维归一化动作 [-1,1] 仿射映射为 [-5,2.5] m/s²，再执行既定幅值和 jerk 限制。
没有额外 CoopGate 证书过滤。旧 Gym 四元返回值的奖励为活动车辆的负增量团队成本，
决策周期 .5 秒。safe 保留碰撞/路由几何违反；stable 为安全且所有车停止，并且
在已知增益、执行器状态和外部扰动界下继续制动不会再次加速。预测可越过任务截止
继续 10 秒恢复尾段，扰动带前缀与原回合完全一致；达到尾段上限则判不安全，防止
上游不带步数限制的恢复循环不终止。正式回合仍在原 25 秒或完成时终止。

**本诊断的规划器能克隆真实动力学和未来扰动带，具有特权模拟器信息。** 它与只用
可观测状态和模型的部署控制器不属于公平信息条件，不能用于主比较。当前 critic
恒为零，尚无 DMPS actor/critic 训练。后续必须分别处理规划模型信息、原训练流程、
评价 reset 同步修正及预算，不能把这个诊断直接改名为完整方法。

执行前提交桥接、驱动和测试。固定 seed 139892001/139892002，nominal 场景，uniform
扰动，四种 plant，共 8 个开发回合，每个最多 12 个实际决策（不是完整性能回合）。
先校验同动作恢复重放和两级嵌套快照，再由原 MCTSPlanner 做 12 步或到终止。
原参数 gamma=.99、num_iters=4、branch_factor=4、path_len=2、single_action=True，
搜索 seed=804800+设置索引，提案固定为全 1，critic 为零，不挑选获益轨迹。
每次 check_action 后核对主环境完整状态；真实 take_step 的净轨迹增量必须为一步。
逐步独立重算执行器递推、扰动索引和运动学，核对所有实际轨迹。固定输入失败则保存
错误并停止，不换 seed；中断不会自动重跑。所有运行保存原始证据与源文件哈希。

验证范围仅为这些固定开发前缀，不增加正式风险研究独立样本，不汇总控制器收益。
