# 相邻证书复用的对称顺序重放计时

这是首次 48 回合开发比较完成并查看结果后的附加计时协议，执行前单独提交。
首次比较的 24 个实现配对均保持全部原非计时字段一致，预测证书子步减少约 49%，
观测总回调耗时减少约 5.4%/5.5%。但按配对索引交替顺序与内层两种规则相互关联：
名义规则始终旧实现先执行，多路径规则始终新实现先执行，不能排除顺序和系统负载影响。
原始结果完整保留，不修改顺序记录、不替换输出、不将首次时延当作确定加速结论。

新试验使用完整的同一批 24 条已验证轨迹，每条对应三个固定模型之一、四类动力学之一
和两种规则之一。重放全部决策和终止错误，不选高速/低速案例；不新增 SUMO 执行，
也不新增独立场景。对每条轨迹执行两轮，每轮重新构造两个控制器，从初态按记录的
命令历史和状态序列递进。每一步两种实现都必须重现原命令和证据。

执行顺序由 `(案例索引 + 步索引 + 轮次) % 2` 固定。第二轮与第一轮的相同步骤顺序
相反，所以每个确切决策输入都经历一次 old→new 和一次 new→old。计时只包围实际
select 调用，结果核对和存储不计入。预热沿用同一固定开发状态，并排除预热耗时。

报告逐规则/实现的全部调用总时长、均值、P95、最大值、超过 500 ms 次数，以及每轮
和合并的时长变化。原轨迹中的初态、模型和步之间相关，不能把调用数当独立样本做
显著性推断。它是固定输入的计算比较，不能代替真实仿真延迟、通信延迟或硬实时评估。
不使用新的结果选择模型、路径、阈值或修改任何冻结实验。源/模型/输入块 hash 与
完整调用数量都必须一致，发生输出偏差则保留前缀并停止，不重新抽取输入。
