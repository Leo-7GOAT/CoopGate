# V39 固定恢复族的联合风险—采用—收益判定

V38 的条件伤害证书是必要条件，但不是完整部署条件。仅证明
`P(H=1 | A=1) <= 5%` 不能排除两类退化：门控几乎永不采用学习策略，或者采用后平均没有可确认的收益。V38 代码也只把执行失败作为旁列字段，没有把它与主风险结论做逻辑合取。因此，V39 不改变任何已冻结控制器，而是预先固定一个更严格的统计判定。

## 固定且不可拆分的命题族

模型顺序固定为 `(1802, 1812, 1822)`，不得利用校准或确认结果删模型、换顺序或拼接不同模型。对每个模型同时要求：

1. 完整混合分布的采用后条件伤害风险不超过 5%；
2. 强执行器滞后子分布的采用后条件伤害风险不超过 5%；
3. 独立确认集上的采用概率至少为 20%；
4. 相对同初态共同基线的平均配对团队成本收益超过 0.5%。

此外，3,072 个校准初态与 1,024 个确认初态中的共同基线和三个候选执行必须全部完成。任何一次已观察执行失败都拒绝部署。有限样本中观察到零失败不等于证明总体失败概率为零，所以该项只表述为工程验收条件。

四类执行器在校准集中各出现 768 次；每类内部的场景、初态与实际扰动按预声明分布独立同分布抽样，不能再强制补齐内部 cell。校准数据只签发六项风险证书；采用率和收益使用另一个 1,024 初态的冻结确认集。确认集从完整混合分布独立有放回抽样，不强制各类动力学样本数相同，不因 cell 缺失重采样。确认结果不能选择模型或改变阈值。

**执行前统计修正（2026-10-24）：** 原稿把固定分层的校准样本合并后当成 IID 二项样本。不同动力学的采用率和伤害率并不需要相等，合并采用数下的伤害分布不能直接假设为二项分布。下文的分层比例界替代这项未经证明的合并界。V39 尚未开始数据收集，此修正不查看或改变任何冻结实验的结果；旧 V38 推断仍只适用于其 IID 混合采样前提。

## 第二次尝试的固定误差预算

反复开发采用可求和预算

\[
\alpha_a=\frac{0.05}{a(a+1)}.
\]

本协议只能作为第二次统计尝试，因此所有 inferential component 固定使用
`alpha_2=0.05/6≈0.008333`。不能把一次失败的 V39 运行称为新的“第二次尝试”并再次使用同一预算。

整体科学备择是上述十二项不等式全部成立，原假设是“至少一项不成立”的并集。这是交并检验。令各固定项的一侧 p 值为 `p_j`，则

\[
p_{family}=\max_j p_j.
\]

只有 `p_family <= alpha_2` 且全部对应下界/上界越过预声明阈值才通过。十二项之间不再除以十二：若联合命题为假，至少有一项原假设为真，而“全部通过”必然包含错误拒绝该项，其概率不超过 `alpha_2`（收益项仍受下述 t 推断前提限制）。混合风险这一项**内部**构造比例界时需要另行分配误差，不能把这两层问题混淆。这不允许通过后自由挑选某一模型；结论始终属于完整三模型族。

## 条件伤害、采用下界与配对收益下界

强滞后风险在同一动力学层内沿用精确二项检验。观察伤害采用数 `K` 和采用数 `N`，检验边界风险 0.05，并要求一侧 Clopper–Pearson 上界不超过 0.05。`N=0` 时 p 值和上界均不能通过。

对混合风险，设四层总体权重固定为 `w_s=1/4`，层内采用概率为 `a_s=P(A=1|s)`，采用且受损概率为 `q_s=P(A=1,H=1|s)`。真正的混合条件风险是

\[
R=\frac{\sum_s w_s q_s}{\sum_s w_s a_s}.
\]

每层以全部 768 个初态为分母，分别对 `q_s` 求一侧 Clopper–Pearson 上界 `U_s`、对 `a_s` 求下界 `L_s`；每个界使用 `delta=alpha_2/8`。联合界不需要这些计数彼此独立。由 union bound，所有八个界同时有效的概率至少为 `1-alpha_2`，因此

\[
R\le U_R=\min\left\{1,\frac{\sum_s w_s U_s}{\sum_s w_s L_s}\right\}.
\]

分母为零时取 `U_R=1`。这不要求每一层的条件风险都小于 5%，保留原定混合总体目标。对嵌套的 `U_R(alpha)` 求逆得到保守 p 值，再与强滞后及其他目标作交并检验。实现使用预声明总体权重，不用采用样本中的层比例替代它们。

该修正有真实的统计代价：在四层均零伤害且各采用 154/768（20.05%）时，混合风险上界为 **5.63%**，不能通过；各采用 192/768（25%）时为 **4.37%**，可以通过风险项。在相同零伤害配置下至少各需 171 次采用。以上是合成计数的设计检查，不是 SUMO 结果，也不保证实际功效。样本量仍为 3,072，阈值仍为 5%；不能把原先约 20% 采用率的功效预期当成必然可认证。

确认集中模型 `m` 的采用数为 `S_m`，总初态数固定为 1,024。采用检验使用

\[
p^A_m=P\{Bin(1024,0.20)\ge S_m\}
\]

及误差水平 `alpha_2` 的一侧 Clopper–Pearson 下界 `L^A_m`。必须有 `L^A_m >= 0.20`。因此，样本采用率恰好达到 20% 仍不足以证明总体采用率至少 20%，零采用更不可能通过。

对每个确认初态，先用同一初态、动力学与扰动下的候选团队成本和共同基线团队成本计算配对百分比收益。模型 `m` 的 1,024 个配对收益为 `G_im`。V39 使用一侧 paired Student-t 下界

\[
L^G_m=\bar G_m-t_{1-\alpha_2,1023}\,s_m/\sqrt{1024},
\]

并要求 `L^G_m > 0.5%`。均值略高于 0.5% 但区间下端未越过阈值时必须失败；经验方差为零也按不可检验处理，不能产生“无限确定”的合成证据。该收益界在独立同分布正态 cluster gain 下是精确 t 推断，在一般有限方差分布下是大样本近似，不冒充有限样本分布无关保证。风险和采用部分由精确二项界及上述有限样本联合界构造。

最终部署判定是：六项风险、三项采用、三项收益全部通过，并且校准和确认阶段的共同基线与候选执行失败总数严格为零。平均收益不能抵消单车伤害，低条件伤害也不能抵消低采用率或无收益。
