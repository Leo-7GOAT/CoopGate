# 名义恢复稳定集：指令记忆边界的修正

第一次可观测状态接入的完整结果保留不变。随后审查稳定集时发现：只检查完成车辆
已经达到限速还不够，上一条命令的变化率约束也必须进入终端条件。

## 反例

三车位置为 `[100,80,93.2]` m，速度全为 `20` m/s，上一条命令为
`[-5,2.5,2.5]` m/s²。ego0 与 ego2 同车道，初始间距为 6.8 m；当前几何安全。
旧实现将它判为稳定，但完成车辆的巡航命令受每次 2.5 m/s² 的变化限制，下一条
命令为 `[-2.5,2.5,2.5]`。前车减速而后车继续限速运动，第一物理子步即缩小间距，
一个控制周期后位置为 `[109.625,90,103.2]`，安全条件已经违反。

因此原协议中的“该集合不变”声明缺少指令记忆条件。本反例可由测试直接重现。
原部署实验的十个回合都在目标线前停止，未覆盖这一状态；不能因此忽略定义缺陷。

## 修正及证明范围

记 `A={i:p_i<g}` 为未完成车辆集合，速度上界为 `vmax`，上一条命令为 `u_prev`，
每周期允许的命令变化为 `delta=jmax*decision_dt`。新终端条件要求：

1. 当前满足路由分离和冲突区域约束。
2. 对 `i∈A`，`v_i=0` 且 `u_prev_i≤0`。
3. 对 `i∉A`，`v_i=vmax` 且 `u_prev_i≥-delta`。

对未完成车辆，备份制动命令非正，名义速度截断使其保持静止；位置不变。
对完成车辆，巡航映射为 `min(amax,u_prev_i+delta)`，由第三项知它非负。
速度上限截断使车辆保持 vmax，其下一条命令仍满足第三项。完成车辆均已越过
冲突区，彼此速度相同，间距不变；与静止未完成车辆的间距不减，因而保持几何条件。
集合成员身份也不改变。此结论针对既定确定性名义动力学及几何判据。

稳定识别使用精确截断速度 0/vmax，不用近似相等替代无限期保持的条件。代码中的
70 步搜索截止仍会结束检查：上面的不变性是物理状态与命令记忆的性质，不是包括
有限搜索时钟在内的增广状态不变性。它也不是对真实滞后、增益偏差或扰动的保证。

新增 `NominalModelEnvV2` / `ObservableDMPSV2`，只收紧终端集识别；旧源码、旧
权重和原始输出均未改动。该版本尚未替代任何冻结实验，也尚无新的真实仿真收益结果。
