# 已知条件占比变化下的风险与采用率边界

本附加推导针对固定控制器与固定分层抽样设计。它复用现有 `stratified_risk.py` 的
同时分层置信界，补充部署时各类条件比例变化的解释；不修改 V42 正式计划，不读取
正在采集的部分结果，也没有为最终控制器生成新的实测证书。

## 前提和命题

令 C 为已知条件类别，A 表示完整回合中发生过学习采用，H 表示按既定定义发生退化。
每层概率为 q_s=P(H∩A|C=s)、a_s=P(A|C=s)。校准在每层内部独立同分布，控制器、
阈值与结果定义在数据生成前固定。对每层 q_s 的上界 U_s 和 a_s 的下界 L_s 分别分配
α/(2S)，由并集界得到共同事件 E，其概率至少为 1−α。在 E 上所有层同时满足
q_s≤U_s 和 a_s≥L_s，不要求同一回合的两个计数独立。

部署只改变 w_s=P(C=s)，每层内部的条件分布保持不变。允许的权重集合为

    W = {w : sum(w)=1, lower_s <= w_s <= upper_s}.

如果 min_W sum_s w_s L_s > 0，则在同一个 E 上，对所有 w∈W 同时有

    P_w(H|A) <= min(1, (sum_s w_s U_s)/(sum_s w_s L_s)),
    P_w(A)   >= sum_s w_s L_s.

因此取第一个右端的最大值和第二个右端的最小值，得到整个 W 的统一风险上界与采用率
下界。这不是在每个权重上重新检验，无需再按权重数量分配误差；支持连续权重集合。
这里的 α 仍必须预先固定，不能看到结果后选择有利的置信水平或控制器。

若最小分母为零，程序返回风险上界 1、采用率下界 0，不把未观察到采用当成安全。
风险与采用率下界同时通过，仍不能推出平均收益改善或物理安全。

## 为什么有限顶点足够

W 是有界多面体。除至多一个自由坐标外，将其他坐标固定到上下界并用 sum(w)=1
确定剩余坐标，枚举出所有可行顶点。线性采用率下界的最小值在顶点达到。

对风险比值，写 w=sum_j λ_j v_j。当全部顶点分母正时，

    (U·w)/(L·w) = sum_j [λ_j (L·v_j)/(L·w)] * [(U·v_j)/(L·v_j)].

方括号中的权重非负且和为 1，因此任何内部比值不超过顶点最大比值。若某顶点的
分母为零，则按上述规则不授予非平凡的统一保证。这给出有限枚举的完整性理由。

实现将输入二进制浮点数转为精确有理数，枚举顶点并计算线性和与比值，最后将风险
向上、采用率向下舍入。该精确性仅针对输入的数值界；SciPy 的 beta 分位数本身仍为
普通浮点计算，没有声称经过区间算术验证。当前最多支持八层，项目实际使用四层。

## 检查与解释

11 项检查通过，包括固定权重与原界一致、零采用、不可行权重集合、类别重排，以及
十二个固定随机生成问题与独立 Charnes–Cooper 线性规划求解结果一致。测试还保留了
两个反例：某层退化较多时，提高该层权重会破坏原均匀混合的风险结论；某层很少采用
时，提高该层权重会破坏采用率下界。数值例子使用人工计数，不是新增仿真证据。

这是标准分层置信界与线性分式优化的组合推导，不单独声称理论原创。它的用途是为
固定控制器报告可解释的适用范围，而不是把“在一个混合分布上通过”扩大成任意分布
下成立。每层内部噪声、场景难度、动力学、观测方式变化均不受此结论覆盖。

对多个固定模型，当前接口仅返回单模型的统一界。若要挑选通过的模型，必须另作
多重选择控制；原 V42 的“全部固定模型同时通过”交并检验也不能被说成所有单独置信
区间具有联合 1−α 覆盖率。原确认集的平均收益界只对应其原分布，不随该权重分析转移。

所有输出明确设置 `joint_deployment_certified=False`、`gain_certificate_transferred=False`、
`physical_safety_certified=False`。正式验证完成前，本模块只用于推导和开发检查。
