# 跨决策精确缓存的完整SUMO核验

三个固定模型、四类扰动、两种实现完成24次实际SUMO配对运行。16项边界与连续调用测试通过，实际仿真进程返回零；277个配对决策的命令、状态、扰动、逐车结果、完整候选及准入证据一致，9次学习采用全部保留。独立复核重建24条物理轨迹、554个候选集合、18次已准入预测及7个不同的完整扰动预测。

| 扰动 | 原实现 select 总计 ms | 精确缓存总计 ms | 墙钟减少 | 内部模型工作减少 |
|---|---:|---:|---:|---:|
| clean | 14428.91 | 14194.84 | 1.622% | 0.0296% |
| uniform | 15285.22 | 15180.66 | 0.684% | 0.0048% |
| bias | 5130.27 | 5116.02 | 0.278% | 0.0049% |
| pulse | 13999.46 | 14096.85 | -0.696% | 0.1079% |

全部模式汇总，select墙钟只减少0.523%，内部模型推进只减少0.0416%；脉冲模式略慢。因此该实现通过了行为等价验证，但没有形成明显加速，不纳入正在校准的主控制器。各决策的计算仍然完整执行；新增缓存只复用精确相同配置、状态、上一命令与时钟下的确定性基线命令。

最大保留缓存为3,007项，调用中瞬时最大3,093项。8,192项限制作用于两次调用之间的保留量，不是瞬时内存上界；这些数值不等于实际内存字节。配置改变、时钟回退与异常会清空缓存，过期与超过保留容量的条目被淘汰，全部开销计入select计时。

这组实验使用同一个旧初态，新增独立样本数为零，无法据此估计总体时延分布或宣称硬实时。缓存命中不足说明下一步应检查每次基线续跑内部的重复物理检查和候选计算，而不是扩大缓存后假定会加速。风险校准和比较方法保持原冻结实现。
