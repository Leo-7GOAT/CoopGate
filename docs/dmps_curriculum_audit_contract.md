# 课程训练三方实验：测试前固定的独立审计

审计实现与五项检查已提交。绑定时实际训练进程存活，工作量为 3,968/32,768，
训练尚未完成，两个策略评估目录与传统基线目录均为空。协议和原生启动文件的
哈希、审计源码/测试源码哈希、当时训练进度与时间记录在独立不可覆盖的合同中。
它不修改正在执行的训练程序，也不读取测试结果来决定通过标准。

完整运行实际成功退出后，审计依次验证：

1. 原运行协议、所有封存文件和源码身份；初始六组未训练权重与旧配方逐项相同。
2. 每回合课程阶段由累计真实决策数推导；原生目标/实际初态和时间零点吻合，
   执行期间每个物理子步独立重建。测试目录不得含课程初始化，场景必须为原nominal。
3. 每条实际观测、下一观测、奖励、动作及吸收标记；独立重建五个回放数组，
   分开核算真实样本和原算法惩罚样本，并核对优化器更新次数。
4. 新策略、旧策略、传统基线各自全部十个条件。原生失败保留；逐条重放传统
   基线命令。任一相关方法/基线失败就不报告该配对族的完整范围成本收益。
5. 区分原MCTS是否接受actor提案，与实际命令是否不同于传统恢复参考。后者用
   实际命令历史驱动只读参考重放；参考不可计算时不能把它记为“零采用”。

测试包含两个跨动力学重复的初态，不按十个独立样本计算置信界。原MCTS调用
计时只是该规划调用本身，不等于包含actor、观测处理和执行的完整部署耗时。
本开发修复实验不新增风险证书，也不构成已有方法族优越性的推断。

五项检查使用已经封存的真实SUMO课程探针作为固定夹具：正常轨迹可通过；
改动奖励、把课程重置伪装成普通测试、改动阶段信息都会被拒绝；不可用的影子
参考会产生不可评估采用，而不是零采用。夹具未重新采集，也不计入新训练效果。
