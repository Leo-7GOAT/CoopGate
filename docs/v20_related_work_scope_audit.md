# 门控与动作修正的相关工作边界核对

核对日期：2026-10-19。本记录用于约束论文贡献表述及比较口径，不是新增基准成绩。当前 V19 独立确认和 V20 开发实验均继续使用各自已冻结的协议。

## 原始论文与本项目的关系

| 原始工作 | 本次核对的研究目标 | 对本项目贡献与实验的约束 |
|---|---|---|
| [Distributed Simplex Architecture，2020](https://arxiv.org/abs/2012.10153) | 给多智能体系统构造分布式运行时安全保障，并由局部安全条件建立整体安全结论。 | 不能声称首次将 Simplex 或安全切换引入多智能体。我们的逐车性能耦合反例不反驳其物理安全定理。 |
| [Simplex-Drive，2021](https://arxiv.org/abs/2109.13446) | 在学习型高级控制器与基于速度障碍的安全基线之间按安全条件切换，并验证自动驾驶场景。 | 不能把“RL 与传统控制切换”本身作为创新点。本项目的基线、场景和指标不同，没有完成该论文的原样复现。 |
| [Predictive safety filter for learning-based racing control，2021](https://arxiv.org/abs/2102.11907) | 预测安全过滤器检查学习输入；必要时提供替代输入，维持赛道边界约束。 | 动作修改和低干预本身已有先例。衰减候选的价值须由相同学习器、相同基线下的联合性能检查与配对消融支持。 |
| [Predictive safety filter using system level synthesis，2023](https://proceedings.mlr.press/v211/leeman23a/leeman23a.pdf) | 在线联合设计安全备份轨迹与反馈管控制器，以减少线性不确定系统的保守性。 | 扩展扰动预测不能据此宣称优于鲁棒预测安全过滤器；双方动力学、备份设计和计算开销应分别交代。当前没有复现其 SLS 求解器。 |
| [Safety-Aware Performance Boosting，2026](https://arxiv.org/html/2603.19361v1) | 通过调度预测安全过滤器的 Lyapunov 下降要求，保持稳定性和约束，并扩展可达的安全稳定轨迹集合。本文第 II 节明确采用无噪声动力学，性能不确定性来自初态。 | 不能把“降低过滤保守性且保持安全”作宽泛首创。其稳定性／轨迹集合结论与本项目在时变扰动下、采用学习之后的逐车相对性能退化概率是不同目标，当前没有完成该方法的运行对照。 |

以上边界来自所列原始来源；对本项目比较范围的判断是结合当前实现作出的分析。它不是对全部文献的穷尽检索，也不证明本项目具有首创性。

## 当前可以实际比较的对象

V19 冻结实验对同一三份训练模型、同一强基线、同一初态与外生扰动执行原始学习、名义性能门控和严格有限扰动路径门控。所有方法共享同一物理过滤条件，避免把物理约束差异混成性能门控收益。

已有统计方法的对照包含 Learn then Test、conformal 选择和配对完整信息的均值策略改进适配。均值方法不是 CSPI-MT 观察数据估计流程的完整复现；conformal 边际覆盖也不能改写成采用条件下的风险证书。具体实现、校准和限制见 [V19 公平对照协议](v19_established_comparison.md)及[完整校准结果](v19_calibration_results.md)。20,480 次独立最终比较运行、156 次完整部署回放及独立报告核验现已完成；[最终结果](v19_final_results.md)表明三份严格门控模型保留收益与采用率，但仅模型 1812 同时通过原定全部条件。本文自身使用 LTT 认证，不能将比较表述为优于 LTT。

V20 时变路径实验固定学习模型、基线、候选组合、排序和阈值，只改变预测路径集合。因此它能隔离检查预测路径覆盖的作用。6,656 次完整闭环及全部剩余退化的 38 次回放均已完成；[结果](v20_temporal_development_results.md)显示更严格的检查降低采用率，尚未达到联合目标。动作衰减保持相同路径和物理约束的 640 次小样本闭环也已完成，另有同一 128 初态上的配对扩展；不能将不同初态上的平均数当作改进幅度。

## 当前可辩护的研究问题

本项目重点是：在学习动作会改变其他车辆后续反应的情况下，能否保留实际采用与收益，同时控制相对同一反馈基线的逐车成本／时间退化风险。现有支持包括三车联合动作检查、配对基线价值分解、采用条件风险的独立统计校准，以及完整失败回放。

这些组成部分的数学基础已有先例。论文的方法贡献仍需要靠有效的联合门控设计、可重复的性能与风险取舍，以及与已有方法目标一致的实测比较建立。增加预测路径或插值权重本身不足以支撑强创新性结论；当前结果也不支持宣称全面优于上述原始方法。

训练层面的[目标对应关系核对](v20_training_gate_alignment.md)进一步区分当前团队平均联合策略回报与门控的逐车基线后续价值条件。势函数奖励塑形的政策不变性有既有理论基础，单独改写奖励不能作为新约束或新保证；当前尚未执行该方向的训练消融。
