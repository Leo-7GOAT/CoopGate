# 学习目标与性能门控的对应关系

本核对基于已经冻结的训练及门控代码，用于解释候选生成与准入要求的差别。它没有修改训练权重、损失、当前实验或验收目标，也不把代码中的差别直接认定为退化的因果来源。是否改善效果仍需配对消融和新的独立验证。

## 已实现的目标

| 维度 | 当前多智能体训练 | 当前联合性能门控 |
|---|---|---|
| 优化指标 | 三辆车到达时间加自身控制变化量成本的平均值 | 每辆车的成本与到达时间分别不退化，且团队名义成本严格改善 |
| 当前动作后的续跑 | 冻结的完整联合学习策略继续决策，其他车辆持续反应 | 共同强反馈基线继续决策 |
| 扰动 | 采集访问状态时包含四类隐藏扰动；标注反事实分支使用零扰动 | 检查固定的 17、33 或 49 条完整扰动路径；库外风险另行校准 |
| 可保证的层次 | 自生成联合回报驱动的三个 actor 更新；神经近似不能自动继承精确策略改进结论 | 精确条件下的有限路径逐车性能关系，以及特定冻结策略的独立总体条件风险认证 |

训练中的 `nominal_returns` 在首动作后继续调用当前联合模型；`unilateral_returns` 将三车成本取平均生成单个 actor 的反事实动作表。数据聚合训练保持其他 actor 和参考联合策略冻结，并按三辆车轮流更新。代码来源为 [cooperative_iteration_v16.py](../src/coopgate/cooperative_iteration_v16.py)、[train_dagger_cooperative_v17.py](../tools/train_dagger_cooperative_v17.py) 和 [train_cooperative_iteration_v16.py](../tools/train_cooperative_iteration_v16.py)。这些事实不改变其模型驱动多智能体策略迭代的算法身份；当前没有把它改称 MAPPO。

门控来源为 [portfolio_gate_v19.py](../src/coopgate/portfolio_gate_v19.py) 与其时变路径、动作调整扩展。候选通过名义排序后，仍须对同一完整联合动作检查所有车辆、成本与时间分量。模型访问过扰动状态，不等于训练时已经对其未来扰动进行鲁棒评估。

## 数学上的差别

记联合学习策略为 `π`，强反馈基线为 `b`，成本为 `c_i`。训练动作表针对：

```text
Q_i^π(z,a) = c_i(z,a) + V_i^π(f(z,a))，
最小化 (1/3) Σ_i Q_i^π(z,a)。
```

而成本门控使用：

```text
δ_i^b(z,a) = c_i(z,a) + V_i^b(f(z,a)) − V_i^b(z)，
要求对每个 i 都有 δ_i^b(z,a) ≤ 0；到达时间另作同类检查。
```

两者既有续跑价值的差别，也有平均指标和逐分量约束的差别。即使一个动作使团队总成本下降，也可能增加某辆车的成本；到达时间与控制变化量之间的权衡也可能使成本变小但到达时间变长。这些逻辑差别本身不证明重新训练一定有效。

## 仅改成基线优势奖励不会增加约束

考虑当前有限时域、无折扣问题，以状态、上一命令和时钟为完整状态，令终端基线势函数为零。如果在每个实际转移上使用形如

```text
c'_i,t = c_i,t + V^b_(i,t+1)(z_(t+1)) − V^b_(i,t)(z_t)，
```

的塑形成本，则望远镜求和得到：

```text
Σ_t c'_i,t = J_i − V^b_(i,0)(z_0)。
```

在共同初态下，后项与被训练策略无关。因此，单纯把团队平均奖励改写成基线势差，并不会在优化目标里新增逐车不退化条件。它可能影响有限样本学习的效率，但不能自动产生所缺少的约束或风险证书。这是势函数奖励塑形的既有性质在本有限时域设置中的直接推导，相关原始工作为 [Ng、Harada 与 Russell，ICML 1999](https://ai.stanford.edu/~ang/papers/shaping-icml99.pdf)。

上述恒等式使用实际转移的下一状态。若代入名义预测下一状态却在另一扰动轨迹上累计，就需要另计模型残差，不能直接使用这个恒等式。若终端势不为零或改变了截断与失败计分，也需保留相应边界项。

## 后续消融所需的条件

当前固定模型下的动作调整扩展，回答的是候选生成能否补回采用机会；它不检验训练目标改变的效果。若完整结果仍未保住收益与采用率，训练改进应单独冻结父模型、训练种子、数据预算和反事实分支规则，以相同额外预算继续原目标的模型作对照。三个模型都应保留，不能挑选受益的训练种子。

任何候选训练约束都需同时检查未经门控的策略、同一固定门控下的策略，以及实际采用后的风险。物理过滤条件、强基线和评价指标保持可比；新策略须使用新的独立风险校准和最终确认数据。新增逐车惩罚、约束优化或扰动分支会改变训练目标，必须明确报告，不能仅以“奖励塑形”名称宣称自动继承原来的最优策略或新增保证。

现有完整回放已经定位了准入时的后续耦合误差，尚未检验上述训练改动。相关证据见[剩余退化诊断](v20_temporal_harm_diagnosis.md)。
