# 多车共同完成的数据覆盖：真实 SUMO 课程初态接入检查

较长训练已完成全部预算和审计，但 655 个完整训练回合均未完成三车任务，测试
表现为固定一辆到达、两辆停止。这个结果提示应先修复任务完成的数据覆盖，而非
把增加相同步数当作改进。本协议只检查训练初态与物理执行，不训练或排名策略。

课程阶段按实际控制决策数固定：0–8191 为 near_goal，8192–16383 为 post_merge，
16384–24575 为 single_approach，其后使用原 nominal 合流初态。阶段只在 reset
时改变，跨边界时正在运行的回合继续原阶段，不按成功/失败或奖励切换。

前三阶段分别使用共同平移的三车位置 `[39,57,21]`、`[15,45,-15]`、`[-40,35,-75]`，
平移范围分别 ±1、±3、±5 m。共同速度范围分别为 19.5–20、13–16、11–14 m/s。
初态由 seed 和固定独立流生成，不替换无效种子。所有车辆初始都未达到 60 m 目标。
首阶段即使持续最大 admissible 制动也有足够初始动量到达目标，因此能提供真实
三车共同完成数据；随后扩大到上游合流。它改变训练初态分布，不改变实际代价、
动力学、动作约束、网络更新或测试分布，也不是新的研究创新或安全定理。

原 SUMO reset 后，在记账时间零点之前用原生 moveTo/setSpeed 放置车辆、推进一次
初始化物理步并重建距离坐标偏置。必须逐车核对实际位置/速度、无初始化碰撞，以及
名义备份可恢复；保存原生仿真时间原点与目标/实际初态。执行开始后禁止重定位。
不读取未来扰动来选初态，实际回放始终来自原生 SUMO 步进。

固定八个检查条件：四阶段各 seed 159900001/159900002，nominal plant、clean 外扰。
执行最大 admissible 制动及共同 post-goal cruise，最多原 50 步。第一阶段应完成
三车任务；其余阶段可停止未完成，这不是性能对照。每个实际子步与独立名义和真实
运动学重建一致，任何 reset/物理/审计失败保留证据并停止，不换种子。

全部八个条件结束才给接入结论。后续较长训练必须另行冻结预算、种子和测试条件；
本探针没有学习收益、风险证书或对原方法竞争力的声明。正式 V42/V44/V39 不切换
课程初态，之前的失败文件与训练源码均保持原样。
