# 外部噪声一致的跨场景与动力学迁移

V19 迁移研究的控制器比较使用相同初态、执行器参数及外部噪声，但名义动力学的噪声幅度为 ±0.5，其余动力学为 ±0.1。因此跨动力学的差异同时包含执行器变化与噪声变化。V21 增补实验把四类动力学的外部创新统一为 ±0.1 m/s²，用配对闭环实验单独考察声明的执行器干预。

当前状态：13 项针对性测试与 107 次实际 SUMO 集成核验已通过。正式的 12,160 次迁移研究协议及完整源码已冻结，尚未启动。正在执行的 6,656 次 V21 到达时序门控研究保持原协议与源码，其效果尚未读取。

## 物理定义与核验

保持 0.5 s 决策周期、0.1 s 物理子步、三车路线、命令与变化率范围，以及所有控制器原有 ±0.5 m/s² 实际加速度误差假设。名义、增益/阻力、轻度惯性、强惯性使用相同的外部创新序列 w。实际误差 a−u 随动作、速度与执行器记忆变化，因此不同控制器的实际误差可以不同。

执行器满足 a_act,j = rho a_act,j−1 + (1−rho)u，实际加速度为 g a_act,j − d v² + w，rho=exp(−dt/tau)，tau=0 时 rho=0。新核验程序不调用仿真执行器的更新函数，而是独立重建该递推、速度裁剪、位置、到达时间、指令变化与误差越界数。每条记录保存完整外部噪声序列的指纹，每个已执行子步还与预先生成的序列精确核对。

已有解析界继续适用：增益/阻力的误差上界为 0.5；轻度惯性为约 0.4384；强惯性为约 3.3380 m/s²。前两项满足声明的物理误差前提，但不能由此推出性能风险保证。强惯性仍作为超出该前提的范围测试；仿真中止及其后未模拟的运动必须明确区分。完整推导见 [V19 执行器边界](v19_actuator_bounds.md)。

检查包括三模型在四类动力学下原调整门控与关闭额外条件的参考版本的 12 对完整轨迹；与 V19 相同噪声的非名义执行器旧控制器逐条精确回放；两条独立加性仿真参考；全部执行器与物理轨迹重建；全部不同已采用动作的完整预测库复算。已知基线失败必须原样保留，集成通过不要求强惯性下每个控制器都完成。该检查增加的独立有效性样本数为零。

## 正式迁移设计

冻结方案保留五类场景：普通、密集、低速让行、速度不对称、紧密跟车；每类 32 个新初态，四类动力学，共 160 个独立初态簇。种子按 63400001 + 场景序号×1000 + 类内序号生成，已在冻结时与已有协议的连续初态范围及分场景范围核对。[正式协议](../artifacts/v21/matched_transfer/protocol.json) SHA-256 为 `d040543a1b48cee256e420ff6d8a03b297276576a321451b72f5fcfbe5e0a196`。

每格执行 19 个控制器：强规划基线，以及三个固定训练模型各自的原始学习、名义门控、17 路径严格门控、33 路径动作调整门控、50 ms 到达时序门控、100 ms 到达时序门控。总计 12,160 次实际 SUMO 运行。全部模型、两种容差、全部失败与物理轨迹均保留；不根据正在进行的主研究结果筛选模型或容差。

每个场景—动力学—控制器格报告基线相对收益、逐车退化、采用率、完成/中止/碰撞/约束指标、实际误差与计时。以类内初态配对自举，报告新门控相对动作调整门控的增量收益，以及同一初态在不同动力学下的基线相对收益变化。后者使用完全相同的外部噪声，可解释为声明的仿真执行器干预效应；每格样本量仍为 32。

置信区间属于逐格开发分析，不声称数百个区间同时覆盖。该研究不执行新风险认证；旧证书不转移到新的动力学或场景分布。强惯性中的基线失败也计入，不能只报告由失败基线衬托出的较大相对收益。计时来自并发桌面负载，保留完整调用耗时，不作为独占部署或硬实时证据。
