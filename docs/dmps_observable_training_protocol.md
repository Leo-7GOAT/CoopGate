# 从头训练：原版 DMPS 的模型搜索与真实执行边界

上一阶段的随机初始化后 32 步权重在十个条件中停滞超时。不能据此评价原方法。
本阶段验证训练全程无特权预测的接入方式：原作者的网络、ReplayBuffer、run/train
函数体和 TD3 更新均按固定 Git blob 直接加载，不继承任何先前检查点。

## 信息与真实回放

原 MCTSPlanner 仅持有修正后的 NominalModelEnvV2：当前三车位置/速度、上一条命令、
实际决策索引，确定性名义动力学和固定地图/约束。搜索分支不访问 SUMO、真实 plant、
执行器记忆或未来扰动。原规划器提出唯一选中动作后，边界适配器将它执行一次，再把
真实 SUMO 下一观测、实际成本奖励及终止信息交还原训练器。实际观测替换规划器的
当前观测，不把假想转移当作真实回放。

原算法为被替换提案添加的吸收惩罚样本继续保留，并与真实执行样本分开核算。
模型预测不安全、真实几何违反、碰撞、未完成或重置错误全部保留；不另加 CoopGate
动作替换，不换种子。首次模型/接口异常保留证据并结束本次开发运行。

本任务的 25 s 截止属于有限时域 MDP 的吸收终止。原 run 在 `ep_len==max_ep_len`
时默认继续 bootstrap；本适配器显式把该判别属性设为 51（真实执行仍只有 50 步），
从而真实第 50 步的 done 也进入吸收标记。此处是公开的任务语义适配，不是原函数
体修改。评价成本仍为实际完成时间加 0.05 倍指令变化量；训练奖励为每周期未完成
车辆的相同成本增量的负团队均值。gamma=.99 因而对应折扣训练目标，不能把 critic
当作未折扣实际成本的证书。未完成车的有限时域成本按 25 s 截断。

## 固定工程阶段

- CPU、单 Torch 线程；NumPy/Torch 种子 805101，动作采样独立流 805102。
- 从原随机 Model 初始化，原 256×256 网络；256 个真实训练控制决策。
- nominal 场景、nominal plant、uniform 外扰 .1。每次 reset 按预定序号使用
  139896001+i，最多 257 个，不丢弃、替换或根据结果选择初态。
- warmup/batch=32，间隔 8 步做 4 次更新，预计 108 次梯度更新；回放容量 1024。
- 原学习率 .0003、tau=.005、policy_delay=2；ret_low=-32/ret_high=0 只设置
  critic 的仿射输出缩放，不限制其值域。被拒提案吸收奖励 -32。
- 原 MCTS 4 次迭代、4 分支、路径 2、single_action；评估不用探索噪声。
- 固定评估初态 139897001/139897002：nominal/clean 两个，四类 plant/uniform
  各两个，共十个完整条件。与训练种子不重叠；不挑选权重或最佳场景。
- 显式 test_planner.reset 同步观测；所有物理子步、回放、检查点、优化器状态和
  固定输入哈希保存。原作者完整源码在仓库外按 blob 校验后加载。

先冻结实现再执行。全部条件结束并独立重建后才汇总，不对部分效果做策略选择。
256 步是训练边界和终止语义的工程验证，不能代表收敛、完整原论文复现、同等训练
预算或优于其它方法；不产生新风险证书。完整公平对照仍需各方法共享任务、观测、
训练数据和计算预算的充分训练及独立测试，不能用本阶段代替。
