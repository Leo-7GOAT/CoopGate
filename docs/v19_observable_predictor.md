# V19 仅观测初态的名义预测审计

Conformal 对照需要从当前可观测初态预测完整候选闭环。原配对 clean 执行使用相同场景生成种子；只有证明这些预测能从观测重建，才能把它用作部署前预测而不隐含读取真实种子或未来信息。

`ObservableInitialMergeEnv` 只接受三车的初始位置和速度。固定内部 SUMO 构造种子为 19367，将车辆置于观测初态，并将命令历史初始化为任务声明的零命令。外部 seed 和 scenario 标签被忽略，只允许 clean 扰动和原来的 0.5 加速度误差范围。车辆必须位于冲突区之前且处于原可恢复初态集合；它不是任意时刻、任意隐藏状态的仿真克隆。

冻结后，在六个新的开发初态上执行十个完整控制器：标准初始化 60 次，观测初始化 60 次，共 120 次真实 SUMO 执行。实际传给影子环境的外部标签有意与原种子和固定内部种子都不同。

结果为 60 个完整控制器对照、1,392 个配对决策步：

- 初态位置/速度误差为零。
- 所有配对命令一致，轨迹状态在 `1e-8` 容差内一致。
- 逐车到达时间、命令变化、完成/碰撞/中止/约束指标一致。
- 不读取真实未来扰动，预测轨迹中的扰动为零。

每个初态的十控制器完整准备耗时为 12.53、32.26、11.08、24.62、16.67、23.38 秒。计时包括 SUMO 启动、重置及全部影子续跑；机器同时运行其他研究。这项开销必须与选中控制器的逐步耗时分别报告，不可仅引用执行阶段 P95 来宣称对照方法实时。

这些是初始化和预测实现的机制审计，不是额外独立风险验证，也没有证明任意初态的浮点等价。最终对照还需要对按冻结规则选中的完整控制器进行实际 SUMO 回放。
