# 统一实际采用事件，保留原始统计命题

历史`build_record`在原始学习分支按策略调用步数记录采用；性能门控分支记录动作准入。V27新增的物理门控采用同状态实际命令差异。三者需要明确区分，不能将不同事件的条件退化率放在同一列而不说明分母。

本补充统一定义：对决策步t，以实测状态、上一条实际执行命令和同一决策步编号运行固定的强协同基线。如果至少一辆尚未到达目标的车辆，其实际执行命令与该基线相差大于1e-9，则该步采用学习；整个回合任一步采用即构成回合采用。该定义不使用网络置信分数、方法标签、未来扰动或最终收益。

采用事件中的基线动作从当前状态计算；退化事件中的参考结果来自同一初态全程执行基线。这两个反事实用途不同，不能将某一步回退误认为消除了此前已经发生的损失。

## 全范围重算

每条原始记录及其`learned_action_steps`保留不变，额外保存统一定义下的步数与回合事件。审计数据库同时保存原观测状态、执行动作、重算基线动作及逐车差异，允许独立重建采用事件。输入文件与源码在计算前冻结，每个完整初态单独封存；重算错误保留前缀并停止，不按结果补选案例。

基线是实测状态、上一执行命令、决策步与固定配置的确定性函数。因此只在同一初态组内缓存完全相同的输入，且返回数组副本。缓存不会替换运行中的控制器，也不会用近似状态合并结果。审计进程在Windows上以较低优先级运行，其他实验的优先级与源码保持不变。

## 为什么旧证书不能直接转用

设A_old为原声明的采用事件，A_act为统一动作差异事件，H为退化。即使能证明A_act是A_old的子集且P(A_act)>0，也只有

\[
P(H\mid A_{act})\leq\min\left(1,\frac{P(H\mid A_{old})}{P(A_{act}\mid A_{old})}\right).
\]

这是由交集概率和条件概率定义直接得到的上界，不是新算法。缩小采用集合可能提高条件退化率，因此不能只保留有利的事件定义。若子集关系不成立，更不能使用该式。有限样本中事件的对应关系也不能单独证明总体子集关系。

本补充只为已完成开发/迁移数据提供共同口径；原校准的事件定义、检验水平、选择规则和证书保持不变。新的性能风险声明仍需针对明确固定的完整控制器与采用事件独立验证。主风险校准的任何进行中结果均不参与此次审计。
