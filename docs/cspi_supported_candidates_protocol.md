# CSPI 调优支持检查：披露的兼容性接入

这是在已知旧开发数据零支持问题之后新增的接入，不覆盖原失败结果，不将旧安全测试
划分重新称为盲测，也不增加独立样本。该规则在本次新诊断结果前提交。它不修改原作者
函数体、不加入方差噪声，也不修改已冻结的公平比较。

拟合数据仍为原 64 个回合，五个候选阈值仍为拟合评分的 .1/.3/.5/.7/.9 分位数。
只使用原 32 个调优回合检查每个候选的策略分歧支持数和 IPW/DR 影响分数方差。
原选择函数同时计算 IPW 与 DR，因此两种计算都须有非零方差；不按收益正负筛选。
只有零支持或零方差候选被移除，不设置事后调节的最小支持数，不给出覆盖率保证。
阈值端点相等、非有限值、重复候选及无重叠性继续明确拒绝，不悄悄修正原估计器。

剩余至少两个候选时调用原 cutoff_selection，保持 gamma=.05、10000 次高斯模拟、
test_ratio=1。仅剩一个时不搜索，直接将其交给原单候选安全测试；原选择函数的
单候选协方差标量不兼容问题以这一显式分支处理。无候选则不可检验并使用基线。

选择函数接口不接受安全测试或评估数据。每模型候选和选择结果写成独占文件并记录
摘要后，才执行该模型的测试。测试只接收冻结候选；如该族出现零支持或零方差，
整个方法族不可检验，不删测试候选、不重新选择。通过时，CSPI 使用其唯一阈值；
CSPI-MT 在同时通过的候选中选测试估计收益最大者，并保留原序处理并列。
该部署选择属于披露的接入规则。独立检验与有限样本保证仍是不同问题。

诊断输入为已封存 cspi_traffic_development 中三个模型的原 observed.npz，验证全部
输入哈希，模型顺序 1802/1812/1822，选择种子 804620+i、测试种子 804630+i。
随机日志、阈值、切分、拟合参数均不重抽，不读取隐藏潜在奖励。
输出为所有候选的支持数/方差、保留集合、原选择结果、原测试结果和回退原因。
不报告胜过 CoopGate、不作新的风险保证或显著性结论。可将此接口用于后续重新冻结
且有足量独立随机日志的正式方法比较，但本次诊断不能替代该实验。
