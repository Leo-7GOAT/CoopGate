# 原版 DMPS 较长训练及逐条件失败保留协议

前序 256 步接入已独立核验真实回放及更新；强滞后评估的原生失败全部保留。本阶段
按固定预算从头训练，以建立可继续验证的已有方法基线，不继承前序权重，不宣称
训练步数本身代表收敛或同等预算下的优越性。原训练和评估源码保持不变，新增驱动。

## 预先固定的训练

- 32,768 个真实 SUMO 控制决策，原随机 Model 初始化，NumPy/Torch 种子 805200。
- 训练是 nominal 场景、nominal plant、clean 无外扰。这样研究名义模型中学习到
  的策略向失配条件迁移的边界；不把训练环境覆盖解释成已经覆盖全部动力学。
- 第 i 次 reset 用 seed 139898001+i，预定最多 32,769 个，不拒绝或更换初态。
- 单 CPU Torch 线程，warmup=2048、batch=128，每 16 步执行 16 次梯度更新，
  总计 30,704 次 critic 更新、15,352 次延迟 actor 更新。回放容量 65,536。
- 原 Adam 学习率 .0003、gamma=.99、tau=.005、policy_delay=2；目标动作噪声
  标准差 .2、截断 .5，沿用原训练器；探索噪声标准差 .15，独立流 805202，动作
  采样独立流 805201。critic 仿射缩放 -32/0，被替换提案吸收奖励 -32。
- 保留与前序一致的实际成本增量负奖励、有限 25 s 吸收终止、完成车辆巡航和
  修正终端集。MCTS 4 次迭代、4 分支、路径 2、single_action。训练中若出现
  控制器/模型域错误则记录全部前缀并停止；不以额外重置把失败藏入完成预算。
- 假想搜索仅接收可观测状态，真实回放只来自唯一选中动作的 SUMO 执行；原算法
  惩罚样本独立计数。每 128 次真实执行写只含工作量和进程身份的进度记录。

## 固定完整评估及失败规则

最终权重唯一固定为完成全部训练后的检查点，不按结果挑选。评估初态为
149899001/149899002，与训练和前序接入阶段均不相交。条件固定十个：nominal/clean
两个，nominal、gain_drag、lag_mild、lag_strong 的 uniform .1 各两个。

每个条件独立 reset，最多 50 步；控制器错误、名义恢复域错误和 reset 错误记录
为该条件失败，随后继续下一个预定条件。真实碰撞、几何违反和时限未完成亦保留。
不重跑失败条件、不换种子、不追加 CoopGate 兜底。轨迹/回放审计断言失败会中止
整个运行，因为此时证据不可信，不能作为普通控制器失败吞掉。

保存全部实际物理子步、真实状态、计划选择、模型预测、回放、初末权重及优化器
状态。完成训练和十条件评估后，另行独立重建；所有失败均进入分母。十个条件复用
两个初态，不是十个独立风险样本，不生成风险置信保证或部署最坏耗时保证。

这是建立充分训练对照所需的一步。完整公平比较仍须共同的信息、训练数据和预算、
其它方法相应训练、足量独立测试及失败保留。冻结 V42/V44/V39 的模型和样本不替换，
本阶段不得据此输出“优于已有方法”或“已收敛”的结论。
