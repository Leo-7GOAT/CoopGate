# V19 既有方法的匹配对照

该对照在主校准数据收集期间加入，并在读取完整校准结果、运行独立最终测试之前冻结。当前只有实现和协议，尚无该对照的最终性能结论。不会根据正在收集的数据改候选、阈值、训练权重或最终测试种子。

## 共同实验条件

三个训练模型分别保留 raw、nominal、portfolio0 三种完整闭环，共九个候选。各方法共用冻结权重、观测、强反馈基线、物理过滤器、初态与外生扰动，以及 1024 个独立校准初态。选择始终在同一训练模型的三个控制器中进行；不挑选表现最好的训练种子。

最终测试使用新的 512 个 IID 初态，种子 62200001–62200512、四种扰动、十个实际控制器（九候选加基线），共 20480 次 SUMO。每个初态的实际模式通过独立固定随机流 19417 选定，另报告四模式压力组；两种采用分母分开处理。简单/高交互分层是补充分析，不替代全体收益与逐车退化。

## 在线门控与统计准入是两个不同的比较维度

raw 加共同物理过滤器是运行时安全思想的任务适配；nominal 为名义逐车性能门控；portfolio0 为严格扰动库下的联合组合门控。对三者采用相同的风险定义和同一 LTT 检验。本文使用已有统计工具为在线门控校准，不能把“优于 LTT”写成创新结论。

同时增加三个完整控制器选择器，比较不同准入原则实际保留的收益和采用率。它们均可访问相同九候选，包含所提组合门控；因此这些实验比较的是部署规则和保证对象，而非宣称所有候选生成机制都是独立的既有算法。

| 选择器 | 冻结选择规则 | 正确的保证对象 |
|---|---|---|
| Split conformal | 校准最坏模式/候选/车辆/指标的单侧残差，初态上选择全部上界非正且团队改善的完整控制器 | 校准集与新初态联合随机性下的边际覆盖 |
| Learn then Test | 对九候选进行两个采用后风险目标的精确二项检验；每个训练模型内选择已认证且校准平均收益最大的候选 | IID 场景下，采用学习后的退化风险，控制总体错误认证概率 |
| Mean-SPI | 同九候选、同配对样本的渐近联合高斯均值下界；选择下界为正且校准平均收益最大的候选 | 总体平均成本改善的渐近检验 |

无可选候选时使用基线，仍报告零采用和零收益；不把零采用称为风险认证成功。候选与基线同时失败时，仍分别报告物理失败，不能通过两者成本相等隐藏失败。

## Conformal 的预测、故障和计算成本

预测为从可观测初态出发、无外生扰动的完整 SUMO 闭环，候选与基线分别预测再求逐车成本/时间差。它不读取实际未来扰动、实际模式标签或最终结果。配对研究中的 clean 执行可复用为这些确定性影子预测；clean 本身也保留为压力组的一种模式。整个预测器不在校准集上拟合。

令 D 为实际逐车差、P 为固定名义预测，对独立初态 i 使用 S_i=max(D−P)，最大值包括全部模式、候选、车辆和两个指标。任一候选/模式发生碰撞、约束违反、中止或未完成，则 S_i=+∞。按 ceil((n+1)(1−α)) 选择分位数；无穷分位数只允许回退。这样成功完成标志无法被较小成本掩盖。若新初态分数不超过有限分位数，则所选完整控制器的成本/时间上界成立且没有上述失败；其覆盖仍是边际性质，不能推导采用后条件风险。

该共同残差构造是明确且可能保守的 conformal 适配，不宣称是该方向所有方法中最强的一种。参数不根据最终结果调整。完整影子闭环需要较长准备时间，报告全部候选与基线的预测控制计算时间之和；该量不包含 SUMO 启动和 IPC，是实际初始化耗时的下界。执行阶段的 p95 不能替代该准备开销，也不能因此声称在线实时。

## 实际仿真结果与组合统计的区别

最终对照从独立实际执行的十种完整轨迹中，按已冻结选择器选取一条完整轨迹。没有车辆级拼接、未来结果筛选或中途切换。这是全信息配对评估，不额外宣称又执行了六类选择器的全部 SUMO 次数。记录每个选择及其来源，并要求额外的实际 SUMO 完整控制器回放核对；未做回放时报告明确保留 `whole_profile_replays_still_required=true`。

保留校准与最终测试文件哈希，禁止初态交叉、开发集冒充校准集、读取未完成的校准碎片或改动冻结分析源码。最终均值区间以独立初态为单位自举；三个模型的退化比例分别报告。

权重哈希并不足以定义完整闭环策略。`tools/check_v19_evidence.py` 还逐文件核对校准/最终协议中共有的控制器与执行代码、观测/场景生成器、候选定义、扰动模式和模型记录，验证两个初态集合不相交，并绑定比较协议哈希。该检查随 CI 执行，也应在校准及最终评估前执行。

## 执行入口

```powershell
python tools/compare_established_v19.py freeze artifacts/v19/risk_validation artifacts/v19/comparison_plan
# 只有主校准研究完整 finalize 后才允许下一步。
python tools/check_v19_evidence.py
python tools/compare_established_v19.py calibrate artifacts/v19/comparison_plan artifacts/v19/risk_validation artifacts/v19/comparison_calibration
# 先提交校准选择器目录，再生成并提交启动记录。
python tools/start_final_v19.py prepare
# 提交 artifacts/v19/final_launch.json 后，分别启动四个 shard（0..3）。
python tools/start_final_v19.py worker 0
# 四个 worker 全部完成后，finalize 并评估：
python tools/start_final_v19.py finalize
python tools/compare_established_v19.py evaluate artifacts/v19/comparison_plan artifacts/v19/comparison_calibration artifacts/v19/final_confirmation artifacts/v19/final_comparison
```

启动器检查校准目录与启动记录均已提交且未修改，并绑定风险数据、模型、控制源码、候选定义与数据分割。未完成校准的真实工作目录已经验证会被拒绝，且不会创建启动记录。默认不直接调用底层执行器绕过此检查。新的 `nominal_predictor_audit` 另以 6 个开发初态、十个完整控制器进行 120 次 SUMO 执行，核对只用观测初态初始化、固定内部种子、忽略外部标签的名义影子预测；该审计的完成情况以其独立结果为准。

## 方法来源与适配范围

- [Conformal prediction 教程](https://arxiv.org/html/2107.07511v6)：使用标准交换性秩覆盖思想，损失和完整控制器适配属于本实验。
- [Learn then Test，第 3.2 节](https://arxiv.org/html/2110.01052v5)：采用子集中的二项损失与多重检验；不是新统计定理。
- [CSPI-MT，第 4.3 节](https://arxiv.org/html/2408.12004v1)：这里只适配联合均值检验。仿真可获得配对完整信息，未复现原文的观察数据双稳健估计和阈值搜索。
- [Simplex-Drive](https://arxiv.org/abs/2109.13446)：仅作为物理过滤与基线兜底的概念来源，未声称复现其车辆/避障模型。
