# 自车基线相对门控：收益、到达时间与安全分别验证

本阶段将论文主线收回到门控：何时有证据采用学习型控制器，何时返回明确的传统规划基线。复杂交互下学习收益更大是要检验的假设，不能用场景名称或网络置信分数代替证据。只有一个车辆参与学习；尚未满足纯策略单车优于强基线的前置条件时，不扩大到 MARL。

## 目标与控制器

自车目标固定为 Jₑ=Tₑ+0.05Dₑ。Tₑ 为自车首次到达目标的时刻，Dₑ 只累计到该时刻的自车指令变化绝对值。其他两辆车的到达时间单独报告，避免将自车收益建立在未报告的他车损失上。Dₑ 的单位为 m/s²，不等同于实际车身 jerk 或乘坐舒适性。

传统基线 B 枚举同一自车动作格点，以固定规则反馈作为完整剩余时域的尾部，选择较优首动作并在下周期重算。规则尾部总是请求最大可行加速度，再通过共同安全修正器。B 是 rollout 规划器，不是复现某篇已发表 MPC 的结果。

学习器采用标准 dueling Double DQN，每0.5秒用本车观测重新选动作。观测包含本车状态、150米内邻车相对状态、上一执行指令及剩余时间。邻车指令来自本封闭协同仿真中的共享状态，不是从视觉图像无误差估计得到。三组最终检查点各经2,097,152次模型环境转移训练，无行为克隆、规划器标签或初态一次性动作档案选择。不同分支的13个自车提案经过同一联合安全修正器，似然或 Q 值对应原提案，实际执行可以被修正。

Double DQN 的更新目标为 r+γ(1−z) Q_target(o′,argmax_a Q_online(o′,a))，γ=0.995，z 表示到达目标或触及25秒时域边界；动作选择和目标评估采用不同网络，目标网络每250次梯度更新同步。奖励的势函数塑形为 γΦ(x′)−Φ(x)，Φ 是负的归一化剩余路线距离，终止势为零。其折扣和只改变固定初态下的常数项，但折扣目标与报告的未折扣工程指标仍有区别。网络、训练和规划部件均为已有方法，不能作为算法首创。

必须区分两种执行方式。独立网络策略 N 直接输出逐周期提案；学习辅助规划器 L 则将 N 作为额外未来反馈序列，与传统尾部共同参与滚动评价。L 的全部收益不能归因于网络直接执行。对照必须包含 B、N、使用未训练网络的同构规划器，以及使用训练后网络的 L。

## 学习辅助规划的名义性质

将指令记忆与任务时钟纳入状态。设安全修正后的名义转移为 f，阶段代价为 ℓ，固定规则策略和学习策略的剩余代价分别为 V₀、V_N。定义 W(x)=min(V₀(x),V_N(x))。在线规划在相同的可行自车动作集上最小化 ℓ(x,a)+W(f(x,a))。

动作集中包含两种尾部在当前状态的首提案。取实现 W(x) 的尾部首动作，即有 min_a[ℓ(x,a)+W(f(x,a))]≤W(x)。在有限时域终端代价为零、模型完全匹配且尾部可行的条件下，将该不等式逐步相加，得到规划闭环名义代价 J_L(x)≤W(x)。这是经典多策略 rollout 的政策改进性质。

**这不推出 J_L≤J_B。** B 本身也进行了滚动改进，两个改进策略之间没有由上述不等式给出的排序；有执行扰动时也不能直接沿用名义代价界。因此，L 相对 B 的实际表现仍需独立实验和统计门控。本文不能用名义定理替代这一步。

## 同时约束成本和到达时间的性能门控

在合流事件开始前，用名义模型分别模拟 L、B 的完整反馈闭环，得到预测差向量 d̂=(Ĵ_L−Ĵ_B,T̂_L−T̂_B)。模型不读取将来的执行误差。独立校准回合在同一初态和同一外生误差带上成对执行两种控制器，获得 d=(J_L−J_B,T_L−T_B)。两个量均以秒计，定义分数 R=max(d_J−d̂_J,d_T−d̂_T)。

初态分组只依赖当前测量：自车与任一主路车的最小冲突区 ETA 差不超过1.25秒为高冲突组，否则为低冲突组。在每组 n 个独立校准回合中，取 k=ceil((n+1)(1−α)) 阶分数 q，α=0.1；当 k>n 时取 q=+∞。令 U=(d̂_J+q,d̂_T+q)。仅当 U_J≤−0.05秒且 U_T≤0秒时采用 L，否则整次合流采用 B。超出已声明初态校准范围或预测失败同样退回 B。

训练后的模型、分组和预测规则固定，并且校准与新回合在组内可交换时，秩对称性给出 P{R_new≤q}≥1−α。由于 R 是两维残差最大值，这等价于同时覆盖 P{d_J≤U_J 且 d_T≤U_T}≥1−α，无需把两次分别90%的区间误称为联合90%。

记放行事件 A={U_J≤−0.05,U_T≤0}。有害放行事件 A∩({d_J>0}∪{d_T>0}) 包含在联合不覆盖事件中，所以其边际概率不超过 α。更强的“放行后未达到0.05秒改善余量，或到达时间退化”也包含于同一个不覆盖事件。

这一界对校准样本与新回合的共同随机性成立，针对单个固定训练模型，不是给定具体校准集后的条件保证，也不是 P{有害|放行}≤α。三个训练种子不是三个独立交通环境；四种误差重复仍按初态成簇统计。固定测试集的经验覆盖率可能低于90%，必须报告。任意域外分布偏移、反复在线使用同一阈值、事后挑选模型均不直接满足上述结论。

## 与物理安全证书的关系

性能门控每次合流选择一次，安全修正每0.5秒进行。两者检查不同问题：前者比较相对基线的实际任务代价与时间，后者判断首个联合动作及后续备用制动能否保持约束。学习放行不是安全豁免，所有方法均受同一证书约束。

沿用V9的条件：三辆固定路线的全受控车辆、精确状态测量、已知纵向模型和加性加速度误差界±0.5 m/s²、初态在备用可恢复集合内、制动力与指令变化率可执行。联合候选由提案、保持指令、备用制动构成，选择偏差最小的获证书候选。备用制动保留指令记忆，终端全部静止且有能力抵消正向误差。将剩余备用序列和静止终端续接，可得到后继状态的可恢复性。

该安全结论覆盖声明的路线间距与冲突区占用合同；它不是任意几何、未知驾驶员、感知错误、不可控车辆下的绝对物理安全。SUMO在计算期间暂停；本项目不统计通信延迟，不宣称完成真实计算延迟闭环或实车实验。模型运行异常的基线接管另作工程验证，不能把该故障实验纳入无故障校准定理。

## 创新边界与后续门槛

本文检验的具体研究问题是：相对明确基线，同时限制任务成本退化与自车到达时间退化，并在获证书的控制执行中保留学习收益。两维最大残差是标准共形预测的一种直接应用，多策略 rollout 和 Double DQN 也已有成熟先例；目前更准确的定位是有完整可审计证据的研究原型。

Conformal Policy Learning 已研究用共形分位数切换不同控制策略；ARMS 已提出根据场景融合 PPO 与 QP 控制。“复杂场景用RL、简单场景用传统控制”本身不足以宣称创新。尚未进行这些已发表完整系统的同条件复现，更不能从本三车纵向模型推断顶会竞争力。真正的MARL仍需多车每周期独立策略执行、联合训练机制及相应消融；单车网络前置条件未通过时继续保留该门槛。
