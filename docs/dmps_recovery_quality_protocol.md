# 较长训练 DMPS 的同条件传统基线核对

在较长训练结果产生前固定本协议。只有 32,768 步训练、全部十个评估条件、实际成功
退出及全量独立回放审计完成并提交后才可执行；权重固定为训练结束的唯一检查点。
本协议用于检验这份学习控制器的任务收益，不承担完整方法族的公平排名。

复用该训练计划的全部十个评估条件，不选取成功子集：149899001/149899002 两个
初态，nominal/clean 两个条件，以及四类动力学各两个 uniform .1 条件。传统基线
使用冻结 MemoizedRecoveryGate(None, public plant class, 'baseline')，在 SUMO 中
独立运行十次。每个条件保留，失败不补跑；不修改既有控制器、门控规则或评价成本。

双方使用同一初始状态、真实执行器参数、外扰流、地图、控制周期、车辆生命周期及
25 s 截止。学习适配器使用名义恢复模型；传统基线按公开执行器类别使用既有界和
指令历史。这是各自具体实现的比较，不能归因为孤立的门控判据效应，也不能宣称
训练预算或预测器完全匹配。没有替换现有正式公平对照和失配计划。

先保存实际基线轨迹，再独立重建真实执行器与每个物理子步，并用冻结的非缓存
RecoveryJointGate 逐步重放基线命令及证据；验证两者实际初态和外生输入一致。
控制器/reset 错误属于该条件失败，继续后续条件。轨迹或审计不一致则保留前缀并
停止，因为数据身份不可信，不能按普通控制器失败吞掉。

每车成本为 capped finish + .05 × active command variation。任一方失败时，该
条件相对收益不可评估；有任何失败就不报告全范围成本收益。基线完成时，学习
失败或任一车辆成本/完成时间变差均算损害；基线失败时损害为不可评估而非零。
团队成本改善与个体退化分别保留。全条件结束并核验退出后才给描述性汇总。

十个条件只有两个复用初态，不形成十个独立风险样本，也不生成置信保证。基线
不需要训练，DMPS 使用固定训练预算；这里只回答“这份训练后的控制器在这些
条件下是否有实际任务价值”，不能据此推广为某个已有方法普遍优于或劣于另一族。
