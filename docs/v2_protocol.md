# V2 冻结实验协议

## 开发阶段发现并处理的问题

V1中种子7的策略可保持8 m/s而未完成任务；种子19的联合多假设门控有两次碰撞，重放确认碰撞最后一帧均处于全车紧急制动。碰撞对象分别为ego2与human1、ego1与human0；这不能单独证明紧急制动是碰撞原因，却说明紧急指令不等于安全恢复证书。

对5个开发场景的150个决策步进行单步预测审计时，发现关闭SUMO内部连接会导致节点附近约8 m的位置跳变。已中止第一轮V2测试，并把中间数据与代码复制到本地 `runs/v2_pre_geometry/`。保留其审计结果于 `artifacts/v2/audit/`，不将这些中间测试作为正式结果。

正式V2打开内部连接（`continuous_network=True`），仍保留V1默认配置用于历史重现。在修正路网上，匹配MPC预测器的位置RMSE为约0.060 m、速度RMSE约5.75e-7 m/s；同一路网上旧纵向响应近似的位置RMSE约0.073 m、速度RMSE约0.148 m/s。这是特定开发轨迹上的单步审计，不是全状态误差界。

随后在效用函数审查中发现，抵达终点时直接撤销速度奖励会产生不连续下降。已改为截断的前视位置效用，并增加终点单调性回归测试；相应中间实验保存在 `runs/v2_pre_potential_fix/`。正式数据再次使用全新的随机场景，最终协议位于 `artifacts/v2_final/protocol.json`。中间结果不与最终结果合并。

## 冻结学习与评估

- 三个训练种子31、47、59，修正路网上分别从头训练。
- 每种子90个传统策略示范回合，20轮行为克隆初始化，再运行30000步MAPPO，训练中附加0.1权重的教师动作交叉熵。
- 教师由同一规则规划产生；不使用测试场景示范。辅助模仿提高策略基础，不作为门控创新。
- 使用最终训练权重，不按测试表现选检查点。每一训练种子的所有方法共用同一冻结策略。
- V2所有方法均使用相同持续换道执行器和连续路网。与V1数值不作直接效果归因。
- 7种方法：传统、MAPPO、独立门控、V1联合多假设、去收益筛选、去制动余量、完整paired。
- 每模型、每方法15个新ID场景和15个分布变化场景。ID是nominal/dense/braking的均匀随机混合；变化场景使用密集间距且更长的背景前车停车制动。
- 独立认证集100个ID场景，事先冻结传统控制器与3个paired模型。碰撞及任务未完成两类事件，共8个风险检验，整体错误概率0.05、目标回合风险0.05。
- 配置与具体场景在正式运行前保存为 `artifacts/v2_final/protocol.json`。新随机数发生器种子20261014是固定实验标识，不表示研究日期。

## 报告规范

科学比较给足枚举预算（10000 ms软阈值），避免主机并发负载改变候选集合。另在无训练和大规模实验负载时测150 ms软预算，报告完整决策循环耗时和超时次数，不能把软阈值称为硬实时保证。

统计任务成功、碰撞、失败罚时（未成功统一记30秒）、成功回合用时、RL使用比例、切换数、备用未验证次数、MPC失败、门控和整体循环延时。所谓延时是本机计算耗时，**不做通信延迟实验**。

每种子单独报告，传统基线重复结果不作为独立额外样本。ID配对比较与分布变化结果分别列出。认证失败必须照实保留；分布变化测试不能使用ID认证结论。

三个训练种子和简单道路模板仍不足以声称具有普遍性能。理论中的条件、代码中的检查和经验观察分别标注。
