# V19 完整准入检查下的提前拒绝

该优化只减少已经能够证明无法通过的候选所需的计算。最终接受的动作仍须完成原来的全部 17 个扰动预测、全部车辆和成本/时间检查。没有缩短接受动作的预测时域，也没有用近似值放宽准入阈值。

## 乐观到达时间下界

给定当前状态、上一命令和固定预测扰动序列，构造忽略车辆相互约束的轨迹。每一步选择 `u[k] = min(u_max, u[k-1] + jerk_max * decision_dt)`，保留原来的速度上限、单步运动更新和相同扰动。

在这里的纵向积分模型中，速度更新和位置更新对命令及前态单调。这条轨迹的命令逐步不小于任何满足相同命令变化约束的续跑，因此位置构成上包络。其按 0.5 s 决策网格计量的到达时间，是基线剩余到达时间的下界。两者采用相同的有限时域截断；已到达的车辆剩余指标均为零。忽略相互约束只用于数学下界，不意味着这条乐观轨迹安全可执行。

将已经累计的成本/时间、候选首动作成本与该到达时间下界相加，得到 `L`。未来命令变化成本非负，故也有 `L_cost <= Q_cost`。如果任一分量满足 `L > V_baseline + 1e-9`，完整候选值必然无法通过原来的 `1e-10` 容差，可以立即拒绝。否则继续原基线反馈续跑。为保持浮点求和顺序，首动作成本仍在完整剩余成本之后相加。

此实现只适用于严格零失败预算门控。正失败预算被明确拒绝。它不扩大原有限扰动库的覆盖范围，也不产生新的统计风险保证。

## 完整 SUMO 对照

冻结实现和 29 个回放案例后，分别执行缓存版与下界版，共 58 次 SUMO。覆盖三份训练模型、名义/偏置/脉冲/均匀扰动，并保留开发集中的实际退化案例。

- 667 个配对决策步的动作、接纳、联合组合和最终结果一致。
- 150 次名义提前拒绝、82 次扰动库提前拒绝分别与完整原始续跑值核对；下界均未大于完整值，且原候选确实应被拒绝。
- 所有实际接受的动作仍使用完整 17 个场景值；选中动作的性能差与缓存版一致。

| 测量 | 缓存版 | 下界提前拒绝版 |
|---|---:|---:|
| 总控制计算时间 | 79,022.89 ms | 73,620.15 ms |
| P50 | 15.00 ms | 13.80 ms |
| P95 | 703.19 ms | 647.90 ms |
| P99 | 1,665.29 ms | 1,731.51 ms |
| 最大值 | 3,668.77 ms | 3,769.14 ms |
| 超过 500 ms 的决策 | 54 / 667 | 52 / 667 |
| 内部规划转移 | 3,788,486 | 3,452,783 |
| 额外乐观预测转移 | 0 | 124,438 |

总控制时间降低 6.84%，但 P99 与最大值没有改善，500 ms 要求未满足。函数已经预热，版本执行顺序交替，机器同时运行冻结的大样本研究；这不是独占机器的实时基准。不得将此结果与另一组缓存测试的 25.1% 相乘后宣称单个基准上的总加速。

## 剩余瓶颈

在每份训练模型最慢的两个记录状态上做事后剖析，共六个状态。主要开销来自 16 条扰动基线完整续跑与候选续跑，网络提议只占数毫秒。该结果用于定位工程工作，不是新的耗时分布、独立性能实验或安全证书。进一步优化必须保留相同的完整反馈基线和联合准入条件，并额外验证动作等价及总计算开销。
