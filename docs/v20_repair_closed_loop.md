# 完整动作调整门控的闭环开发实验

本实验承接已经完成的 55 状态局部诊断。它比较原 `sampled` 33 路径门控、关闭调整的新实现、完整动作调整门控及同一强规划基线。三个训练模型 1802、1812、1822 全部保留，训练参数不变。

完整门控保留原来的所有联合组合命令，并对每个组合追加固定的 0.75、0.5、0.25 调整权重。新增命令重新通过共同物理投影与证书；等于基线或其他候选的命令去重。每个可执行学习候选仍必须在全部 33 条路径上满足所有车辆的成本和到达时间非退化条件，同时具有严格正的名义团队收益。不能以团队平均改善抵消某辆车的损失。

候选检查依赖当前观测状态、上一命令、固定模型、固定预测路径及当前时刻，不读取实际环境种子、实际扰动模式或未来扰动。增加的预测分支若发生计算失败或产生非有限数值，只拒绝该候选，并记录错误；不会授权执行，也不会删除原候选。

## 预先固定的实验设计

- 新初态范围 63200001–63200016；冻结时检查与既有全部协议的初态范围不重叠。名义与密集初态使用原有等权 IID 混合生成机制。
- 四类实际扰动 clean、uniform、bias、pulse；每个初态、扰动和方法使用相同外生扰动序列。
- 一份基线，加三个训练模型各自的旧门控、关闭调整的新实现、开启动作调整的新实现，共十个控制器、640 次实际 SUMO 运行。
- 保存每次运行的完整轨迹、候选检查证据、实际命令、物理状态、实际扰动、调整权重、错误记录和计算时间。
- `sampled` 路径库的选择依据仅来自已经完成的局部诊断：它与 49 路径库在该诊断上拒绝集合相同且计算路径较少。没有据此宣称两者在完整闭环等价，也没有使用运行中的时变路径实验或独立最终实验结果选取。

关闭调整的新实现必须逐轨迹复现旧门控的状态、命令、采用决定、预测差值和预测工作计数，排除计时字段。新增调整实现则检查原策略采用事件被包含的条件性结论；实际收益和退化计数单独报告，不能从候选集合包含推出。

统计单位仍是 16 个独立初态。重复的四个扰动模式、三个训练模型和两份等价实现均不会扩大独立样本数。该实验首先检验实现正确性并提供开发证据，样本量不足以认证 5% 条件风险。逐项 bootstrap 区间仅作描述，不能作为经过开发选择后的独立有效性结论。

报告保留全部失败、所有新增采用中的逐车退化、真实动作调整次数、p95/p99/最大计算时间和 500 ms 超时次数。并行桌面负载下的计时不是独占硬件部署基准；本实验不引入计算截止时间，因此不能据此宣称已满足硬实时控制。

协议：`artifacts/v20/repair_development/protocol.json`。执行器：`tools/study_repair_v20.py`。独立进程监督：`tools/advance_repair_v20.py`。

开发实验若发现改善，仍需重新冻结策略，并使用新风险校准与独立确认数据。V19 的风险证书和最终测试不能转用于新门控。
