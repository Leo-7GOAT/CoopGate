# 原作者 CSPI 与完整候选因子实验的独立补充比较

## 不改变已冻结实验

输入是尚未开始的 640 个 IID cluster × 五个候选/门控变体的完整因子实验，
父计划 SHA256 为 `437c5386f0c6962e214c3f21d2b997ca40e6f6b6ba336068b7d519823e1830b1`。
本补充协议及程序必须在父实验任何正式结果产生前提交和冻结。它不改变父实验的
控制器、预算、停止规则、指标或已有描述性分析，不读取运行中的任何效果。

选择实验用的是原作者 CSPI / CSPI-MT 统计函数，而不是 advantage-LCB 代理。

84323a8cf90351cf69fbbc59300523ddca54f625；13 个函数体原样加载，不再分发源码。
原支持适配器保持：只在 tune 删除零支持/零方差候选，保留负收益候选；单候选
不搜索，测试族不可计算整族回退。端点相等不抖动、不删除样本、不替换候选。

## 比较的实际问题

CSPI 在回合开始前，在同一个完整 `projected_nominal` 控制器与共同恢复基线
之间选择。与 `projected_bank` 的比较检验：数据驱动回合选择与逐周期扰动路径
门控，在同一冻结学习策略族和模拟条件中分别保留多少收益、采用和退化。
另报 always-baseline、always-projected-nominal，不能只展示 CSPI 的有利子集。

这不是只替换一行门控判据的纯因果消融：调用频率和数据/计算预算不同。CSPI
额外使用 512 条随机观察标签，bank 无需本数据的标签，却承担更多在线预测。
全部预算明示，不宣称等计算或等训练数据优越性。父因子实验的原始 2×2 比较
仍负责隔离候选修复和预测 bank 的机制，不能由本补充取代。

## 预先固定四份数据与随机日志

只使用父实验的 640 个独立初态，一例只有一次随机 model/plant/scenario/mode
抽样，不把模型或方法展开当作新样本。seed 805700 排列，805701 独立产生
Bernoulli(0.5) 处理分配，拆成 fit 256、tune 128、safety-test 128、evaluation 128。
分配清单在任何正式执行之前保存；不按结果重抽或移动单位。

父仿真仍完整执行全部五变体。统计输入从其中预先指定的随机分支抽取，不冒充
实际只执行一臂的新随机化试验，也不新增 640 个独立样本。处理 0 是 baseline，
处理 1 是 projected_nominal；未被分配分支只供封存物理审计及最终配对评价。

仅用初始三车位置/速度六维、公开执行器类别四维、固定策略身份三维为特征。
不使用真实执行器参数、未来外扰、扰动模式、失败/损害标签作为评分特征。
奖励固定为负的团队封顶代价加 25 s 失败惩罚，即 -(J_team+25F)。失败不删除。
这是期望惩罚代价改善，不是采用条件下的逐车损害概率。

标准化器仅 fit 组拟合，两个 Ridge(alpha=1) 只使用各自随机处理臂的观察奖励；
每臂至少八条，不满足则保留失败，不重抽。候选固定为 fit 评分五分位点
0.1/0.3/0.5/0.7/0.9，基线阈值 1e6。调优选择 seed 805720，测试 seed 805730，
gamma 0.05，Gaussian draws 10000，test_ratio 1。阈值选择先独占写盘，才读
safety-test 标签；选择族通过后按原适配器固定规则部署。全部部署阈值及最终
128 条选择先保存，才解码配对评估结果。

## 评价、理论范围与不能混淆的保证

五方法各报全部 128 个评估单位的任务失败、基线失败、采用、采用且退化、采用
前失败、原始成本及固定失败惩罚均值。任一相关方法/参考失败，完整范围成本
收益置 null；惩罚代价仍对全部单位报告。基线失败使相对改善不可评估，不能删掉。

原 CSPI 的独立 safety-test 在其渐近假设下检验期望价值改善，不等价于分布无关
有限样本保证。两个原测试分别报告，不解释为共同 95% 认证。最终控制器对照
保持描述性，不新增显著性、最坏延迟或总体风险证书。

个体损害与均值改善还存在信息边界。设两臂成本边际都为 Bernoulli(1/2)。若配对
潜在成本为 (0,0)/(1,1)，损害概率为 0；若为 (0,1)/(1,0)，损害概率为 1/2。
两种情况下随机日志的 (T,C_T) 分布完全相同、平均差也同为 0。因此单分支随机
日志不能单独识别配对个体损害。本文的配对损害依赖已冻结的同初态、同真实
执行器、同外生扰动的模拟结构；不能宣称比原 CSPI 从相同信息获得更强保证。
这是基本识别边界，不作为新理论首创，也不直接外推实车反事实。

在父实验尚未完成时，本补充只是一份预先固定的可执行分析计划，不是新的比较
结果。即使测试通过，仍需将其与门控收益、采用率和个体退化一并解释。
