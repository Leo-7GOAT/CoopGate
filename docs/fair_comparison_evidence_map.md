# 当前文献对照的证据边界与待完成比较

2026-10-25，基于原论文与本地完整实验。本文只整理证据，不修改冻结方法、预算、
候选集合或统计门槛，不读取正在运行的正式实验效果。尤其不能用已完成但失败的
DMPS 任务适配来衬托 CoopGate 优越。

## 已有工作解决了什么

| 方法 | 原论文已有内容 | 本项目不能声称的首次贡献 |
|---|---|---|
| MAMPS | 考虑智能体间耦合，迭代选择学习/回退组合并检验可恢复性 | 首次联合切换、首次考虑其他车受接管影响、首次尽量保留学习动作 |
| DMPS | 用局部规划和价值估计选择安全恢复动作，并让训练利用恢复计划 | 首次让恢复策略考虑任务进展、首次让规划与学习相互促进 |
| CSPI/CSPI-MT | 对阈值策略作基线相对改进检验及多候选测试，研究渐近检验功效 | 首次统计判定是否优于基线、首次多阈值选择或自动回退 |
| Learn then Test | 将风险校准转为多重假设检验并建立有限样本控制 | 把已有二项检验或多重检验预算直接当成新统计定理 |

以上分别来自 [MAMPS 正文与图 1](https://arxiv.org/html/1910.12639v2)、
[DMPS 第 4–5 节](https://arxiv.org/html/2405.13863v2)、
[CSPI-MT 原论文](https://arxiv.org/abs/2408.12004)、
[Learn then Test 原论文](https://arxiv.org/abs/2110.01052)。随机动力学下的屏蔽也已有
[Statistical Model Predictive Shielding](https://www.roboticsproceedings.org/rss17/p026.pdf)，
所以“增加扰动采样”本身不构成首次贡献。这不是穷尽截至该日所有相关工作的查新。

## 当前完成的对照实际支持什么

V36 完整 8,320 次执行显示，有限扰动性能门控相对标称性能门控减少这组开发数据的
逐车退化，同时保留一定实际收益和采用。但其 MPS/MAMPS 项仍是同物理判据适配器，
不能写成原作者方法的完整复现，更不能由不同计算预算推导门控判据本身的优越性。
详见 [V36 完整结果](v36_full_recovery_gate_results.md)。

原 DMPS 四个作者模块逐字节固定并接入真实 SUMO 训练。名义、课程、执行语义 critic
及可执行区间 actor 的开发配方均保留完整失败；最新配方 32,768 次交互、30 个测试
条件和策略/MCTS 重放均完成，两个学习角色仍各为 0/10，传统基线为 10/10。
这证明该固定预算任务适配尚未学会完成任务，不能外推为 DMPS 方法族无效或被本方法
击败。不能仅因用了作者函数体就忽略任务、奖励、训练预算与模型信息差异。
详见 [最新完整适配结果](dmps_feasible_actor_results.md)。

原 CSPI 的作者函数已做独立开发接入与边界检查，但已有旧开发数据的结果不替代
尚未收集的前瞻性配对比较。不得把本项目的 advantage-LCB adapter 改名为原版 CSPI。
原始观察数据均值检验和本项目可同时观察两个仿真潜在结果的逐车损害目标，信息与
推断对象均不同。新协议继续明确披露这些差异。

## 三组冻结设计分别隔离哪个问题

| 冻结设计 | 覆盖及比较对象 | 能回答的问题 | 保留的边界 |
|---|---|---|---|
| V44 共享证据、失败保留比较 | 640 IID 初态、八种部署选择器、5,120 次执行 | 在相同证据构造计费与协作式截止下，完整选择器保留多少收益、采用和失败 | 候选命令集合仍不同；共享证据计时不是独立部署延迟 |
| 候选集合×门控 factorial | 相同 640 初态、五种变体、3,200 次执行 | 在 raw/projected 候选支持下分离投影与扰动门控的作用 | 没有 500 ms 截止，不能借此当作 V44 的实时排名 |
| 原 CSPI 前瞻性补充 | 从完整 factorial 派生 256 fit/128 tune/128 safety/128 evaluation | 回合级准入与在线门控的收益/退化取舍 | CSPI 使用随机分配的单臂标签，在线门控使用额外预测；不声称等数据、等计算或新有限样本风险证书 |

三组均尚未完成，不能提前给出优越性结论。V44 与 factorial 按原协议要求项目安静
运行，不能与当前正式采集并行后再忽略计时条件。CSPI 导出必须等待完整父实验、
真实退出及审计归档；确认结果不用于重新选择阈值、模型或样本。

执行仍使用 [病例键兼容入口](episode_key_compatibility.md)，只统一封存键的 tuple/list
容器，不改变原数据、判据或统计量。相关协议：
[V44](v44_fair_failure_accounting.md)、
[共享证据](v39_fair_comparison_protocol.md)、
[原 CSPI 前瞻性比较](cspi_factorial_prospective_protocol.md)。

## 仍需建立的研究结论

目标是对同一完整控制器同时报告实际收益、采用率和扰动下采用后的逐车退化风险，
并解释它在明确分布与模型失配条件下何时失效。标准策略改进恒等式、分层二项界、
交并检验与线性分式优化是所用工具，不能把组合本身直接称为理论首创。

完成风险认证还需要原统计尝试完整结束及 V42 两阶段正式证据；扩展适用范围需要
V39 全部 22,464 次执行及按初态聚类的分析；成熟方法优越性需要上表实际完成。
真正 MARL 协作优势还需要相应训练与协作消融，任何作者代码接入或多车仿真都不能
替代这一证明。若证据不支持，应保留失败并重新定位贡献。
