# 后续独立校准的共同数据与对照接口

本阶段为已经冻结的前瞻规则补充数据存储、完整配对检查和最终对照分析。它没有生成新的校准初态，没有改变门控、样本量或风险预算，也没有取得新风险认证。当前 V21 恢复实验继续按原协议执行。

## 逐次提交，保留完整轨迹

`src/coopgate/episode_store_v21.py` 将一次执行的结果和完整轨迹放在同一个 SQLite 事务中，压缩保存并分别记录内容 SHA-256。重复案例不能插入，已有文件不能被新写入器覆盖。每个封存块绑定协议身份和精确执行顺序，分析接口拒绝不完整、顺序不符、校验失败或未封存的数据。

这避免每次执行都重写不断增长的整个结果数组，同时使记录和轨迹一起提交。测试在独立子进程提交一条含失败的记录后直接退出，确认记录和轨迹仍可完整恢复；未封存块仍不能作为已完成样本进入分析。真实中断后仍需保留文件、核查进程和执行显式恢复协议，存储库不会自动重跑或悄悄续写。

## 所有方法共享完整初态簇

`src/coopgate/prospective_data_v21.py` 要求每个初态同时包含四种扰动、基线和全部九个固定候选。它检查初态与种子对应、所有车辆状态一致、完整控制器覆盖、到达时间与控制变化量成本的关系、学习采用计数、所有计算耗时，以及零采用门控与基线的对应关系。遗漏、重复、不同初态混配或非有限的实际指标都会拒绝。

指标保留三辆车各自的成本与到达时间。任意车辆指标退化或候选执行失败都记为有害，即使团队平均成本下降。每个初态只抽取一个预先固定的实际扰动模式；四模式压力组另行取“任一模式采用”和“任一模式有害”。四种扰动、三个训练模型或多次回放都不会增加独立初态数。

最终对照包括原始学习、名义门控、选定门控，以及 LTT、均值策略改进和 conformal 适配。LTT 与均值方法始终使用校准阶段冻结的完整策略选择，不按最终测试收益重新挑选。Conformal 只使用当前初态的完整无扰动预测及预测失败信息；预测是否确实可由观测初态独立得到，以及完整策略的实际部署回放，仍须在执行层另外验证。任何方法都不能拼接不同车辆的结果或使用其他训练模型的策略。

## 已完成的验证

18 项针对性测试通过，包含异常中断、重复写入、失败保留、完整配对、逐车退化、固定选择与测试结果隔离等行为。

随后用新接口复算了已完成的 V19 历史证据：40,960 条校准记录和 20,480 条独立最终测试记录，共 61,440 条。九个候选的两项 LTT 目标、均值检验及其选择、conformal 校准结果，以及六种最终方法在全部三个模型上的风险计数、收益、配对区间、完成数、全部策略选择和计时统计，都与原归档完全一致。

还将一个已有初态的全部 40 次控制器/扰动执行及完整物理轨迹写入新格式，封存后逐项读回，结果完全一致。该验证新增的实际 SUMO 次数和独立有效性样本数都为零。证据见[完整接口审计](../artifacts/v21/prospective_data_audit/audit.json)，入口为 `tools/audit_prospective_data_v21.py`。

## 尚未完成的执行工作

实际采集和独立复核现已接入 `tools/prospective_runtime_v21.py`：复用冻结控制器和 SUMO 动力学，独立重建物理轨迹、原始 actor、名义准入、联合动作候选及每次已准入动作的完整 33 路径预测。三种候选门控的共同控制器族检查和集成调度已通过 5 项测试。

新的实际集成入口为 `tools/preflight_prospective_runtime_v21.py`。它预定在已使用的开发初态 63100001 上执行全部 16 个控制器和四种扰动：64 次新数据通道执行、64 次原执行路径参考，以及 16 次仅由观测初态构造的无扰动 SUMO 预测，合计 144 次执行。结果与轨迹先按事务保存再检查，参考路径的非计时字段须完全一致。预测采用固定内部引擎种子，不读取实际未来扰动。此项检查不使用预留校准／最终初态，不增加独立有效性样本；完成前不能宣称集成通过。

上述实现不是完整的新校准实验。仍须在恢复研究完成、完整模型组通过预定筛选后，将共同控制器执行、全部必要物理复核、观测初态预测、统计分析和部署回放绑定到完整执行协议，完成真实 SUMO 集成检查，并在生成新校准数据前冻结。之后才执行已声明的 4,096 个校准初态和 1,024 个独立最终初态；若原定风险或效果条件不通过，必须保留失败结论，不能用接口测试通过替代科学验收。
