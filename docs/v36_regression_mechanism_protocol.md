# 全部五个既有集合门控退化案例：真实执行器反事实诊断

输入仅为已经完成 8,320 次执行、全量回放并归档的 V36 网格，报告 SHA256：
`1e13918534046bc71b3a39a0ee340c5852357778930dc5cbc8b96cf4eb175162`。
在其中 1,920 个 bank 运行里，全部五个已知退化案例均纳入，涉及四个旧初态，
共八次实际学习采用（每案例 1/4/1/1/1 次）。不选择最好/最坏局部动作，不把
这些已知结果当新独立样本，不读取正在运行的校准、确认或 OOD 效果。

## 固定输入与既有数学工具

从完整报告定位原计划 group，按原/恢复来源寻找正确封存块，验证数据库、封存
和完成回执对最终全量审计的哈希。不能把案例第一个编号误当物理 block 编号。
五个完整 source row、共同基线 row 及完整 trace 再封存为独立只读输入。
源码、运行环境、输入块和八个干预时间在新反事实运行前固定。

复用原 V31 的既有恒等式与实现：在实际轨迹每次采用点，比较“执行原指令一次
然后反馈基线”与“立即反馈基线”的每车成本/完成时间。若这些续接全部完整，
局部差值之和应对应原全回合相对初始基线的差值。原 V34 基线和 V35 预测器
都不改动，也不新建所谓性能分解定理。不可完成/不安全分支保留，完整性能恒等
式标记不可评估；不能用封顶失败代价冒充完成收益。

## 三项离线对照

1. 在原采用状态、上一实际指令、实际执行器记忆、公共命令历史区间和原时钟上，
   用已知真实执行器参数及原未来创新序列预测两条完整基线续接。
2. 同一实际未来序列，但改用原在线参考参数和重建记忆，记录一个模型对照差值。
3. 真实执行器参数/记忆配原来全部 33 条 bank，逐路径保存完整性和差值，不只
   选某条最坏路径。比较真实参数 bank 与真实未来序列能否同样拒绝该动作。

真实参数、执行器内态和未来创新只供事后诊断，不能作为在线信息或新门控规则。
有限路径 bank 仍不是概率，更不因此覆盖任意创新序列。分支独立传播自己的
执行器记忆与命令历史区间，不重用原轨迹的指令相关误差。

## 16 次真实 SUMO 反事实

每个采用点执行两次完整物理运行，总计 16 次。两个分支先从原 seed 重置，再
逐步真实执行全部已记录前缀，包含此前学习动作；不注入位置、速度、执行器
内态或仿真快照。到干预点，按角色取原候选一次或当前基线，之后均使用同一
未改动的 V34 反馈基线。每个采用点轮换两个角色先后顺序。

控制对象只存原前缀位置/指令、当前基线注释与公共类别，不读真实系数、实际
执行器状态或未来噪声。独立测试用会报错的隐藏数组替换这些字段验证此边界。
每步仍执行原停车证书。原生数据持久化后才审计，异常保留前缀，不隐式补跑。

复用现有执行/独立物理递推函数的私有 factory 注入，保持原模块全局变量和函数
体不变。底层记录的 baseline method 是“基线后缀框架”的 wire schema；顶层
明确记录 diagnostic_role 和 source_case，不能把带原学习前缀的分支当完整
共同基线成绩。独立重放全部命令、物理子步、记忆区间、创新和指标，并与离线
预测逐步核对。原初始完整基线的真实参数预测也须与已归档基线指标一致。

实际进程退出 0 后才进行第二遍 verify：核对全部文件/源码/退出身份，重算
八组离线诊断、重新物理/控制器回放全部 16 条记录与既有恒等式。新增记录
不是新风险样本，不产生部署判据、统计显著性、收益排名或新风险证书。

本研究意在区分模型偏差、有限路径未覆盖的实现轨迹、局部正负贡献及完成时间
网格效应；没有预先保证哪种解释成立。预测或恒等式不匹配必须保留并解释，
不得调整损害容差、改变原指标或过滤失败来获得理想结论。
