## 为什么仍然不是新的风险证书

支持规则是在旧开发结果已经被查看之后确定，旧测试标签也已经使用；此次不能恢复
新盲测身份。32 个回合上的渐近检验本身也不是有限样本保证。原始阈值、随机处理分配、
评分模型、调优/测试切分均沿用原数据，没有重新抽样或选取有利模型。

原作者估计器端点约定仍未改写，端点相等输入明确拒绝。兼容性改动是调优候选可计算性
筛选与单候选直接测试分支，必须在未来论文中披露，不能称为完全未经修改的原方案。

## 数据隔离和后续使用

选择 API 只接收拟合评分与调优数据。选择先独占写盘并记录摘要，才传入对应测试组。
若冻结的测试候选族不可计算，整族回退，不能在测试数据上删除不利候选再重选。
CSPI-MT 通过多个候选时的部署规则固定为在同时通过者中取测试估计最大的一个。
10 项检查覆盖这些数据边界、负收益候选保留、零支持、单候选、端点和无重叠性。

三个模型的 IPW/DR 值及协方差都用策略指示函数的独立实现核对，再调用原选择器。
正式公平比较仍需新独立随机日志、明确训练与测试预算，并同时报告作者期望价值指标
和 CoopGate 的采用/逐车损害指标。本开发接口不替换现有冻结八方法实验。
