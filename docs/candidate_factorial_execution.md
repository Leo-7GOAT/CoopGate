# 完整候选族与门控机制实验的执行约定

本执行补齐 V43 的正式收集流程，科学问题仍为候选修正 × 名义/33 路径门控的 2×2
配对消融，另加共同恢复基线。五单元定义、模型、成本、采用与损害判据不改变。
实验比较候选修正效应、门控效应及交互，不能替代原论文完整方法复现。

直接继承已冻结 V44 公平对照的全部 640 个 IID 案例身份：初态种子、场景、动力学
类别、外生创新、模型及所有配对 hash 完全相同。每个案例重跑五方法，共 3200 次
实际 SUMO 执行；与原公平对照不增加独立初态数。一个案例为一个不可替换的封存块，
共 640 块。方法顺序按案例索引循环偏移，再对奇数索引反向，不根据效果调整顺序。

冻结必须发生在 V44 正式执行目录产生前。计划同时记录父计划与绑定、全部当时存在
的仓库 Python 源码、模型及运行环境 hash。后来新增的无关文件不改变已固定清单。
提交源码和本协议 → freeze → 提交计划 → 项目空闲时 watch → 正常终态后 summarize。
冻结不会启动仿真。当前仍优先已有采集、原统计尝试和独立风险验证，不抢占运行任务。

watch/worker/summarize 均检查其他项目任务，不能绕过已有进程或启动平行正式负载。
父进程持有真实子进程句柄，核验 Windows 原生 PID、创建时间和命令，完成握手后才
允许采集；保存实际退出码。观察失败保留同一进程并等待其真实退出，不隐式重启。
已有执行目录、块或最终分析不能覆盖，也不提供自动恢复。

每个回合先写入 SQLite，再独立重放其物理与完整选择器。正常中止、未完成、首次
采用之前失败都保留。沿用 V43 的严格物理证书检查：若发现已声明证书的真实反例，
先保存证据再停止、保留未封存前缀并调查，不跳过样本继续给出全范围效果。此时研究
尚未完成，不能把剩余样本缺失解释为方法成功。

只有全部 3200 回合、640 个封存块、原生零退出、完整 hash 链和二次完整重放通过，
才生成效果报告。重放开始及结束检查同一批回执和块，防止长重放过程中证据替换。
未完成期间不发布部分效果，不挑选模型、场景或阈值。

原 V43 描述性封顶成本结果完整保留，但失败方法的封顶成本不作为有效收益。
新报告分别给出全范围有效收益：某方法或共同基线有任何失败时，该方法收益为空；
某对比涉及的方法或基线有失败时，该收益对比为空。采用、联合损害、失败的配对差
仍使用全部初态，不删除失败对。基线失败使相对收益不可解释，不能通过删基线失败
重新获得正收益。既不把不同采用子集的条件比例当成因果效应，也不签发风险证书。

这里不施加 500 ms 截止，不是同预算对照。所有实际回调时间保留，首回合可能包含
编译开销；不从其时延推出实时性。正式 V44 同预算对照仍按原方案独立执行。本计划
尚未产生正式效果，开发测试与正式案例身份分离。
