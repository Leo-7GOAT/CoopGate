# 预测内相邻重复证书复用：开发验证协议

目标是在不改变动作、候选、扰动路径、阈值和终止条件的前提下减少门控计算。
新增实现独立于冻结 V37/V42/V44/失配/机制消融代码；不替换任何运行中或已冻结实验。

## 等价性的结构依据

原预测先调用恢复控制器：它为名义提案计算停车证书；若失败则为停车备份计算证书。
只有最终返回命令的证书有效，预测才继续。随后预测立即用相同的状态、前一命令、
返回命令、记忆区间、参数范围与配置再次调用相同纯函数，没有任何状态更新。
纯函数对同一输入返回相同结果，因此这一相邻检查可以复用最终有效证书。

修改仅发生在预测内部。外部首次强制候选尚未经过该恢复调用，仍执行完整检查；
恢复失败仍以原错误码停止，不能复用失败证书。实际执行前的物理证书不删除。
物理递推、结果累计、全路径准入、门控选择和所有原逻辑工作计数保留；额外统计真正
执行的预测证书次数/子步与复用次数。编译继续 fastmath=False，不采用近似比较或
跨状态缓存。该论证是纯计算复用，不是新的安全或性能风险定理。

## 固定开发范围

提交本协议、实现、测试和驱动后执行一次完整开发比较：三个固定模型 1802/1812/1822，
四类动力学 nominal/gain_drag/lag_mild/lag_strong，两种性能规则，共 24 个实现配对、
48 次真实 SUMO 回合。全部使用开发种子 139890001、nominal 场景、clean 创新模式；
不按结果选择模型或重抽种子。同一初态跨模型和动力学复用，没有新增独立正式样本。
实现执行顺序按配对索引交替，比较对象为 V37 MemoizedRecoveryGate 与新复用实现。

先在固定无 SUMO 开发状态上预热所有模型/动力学/规则/实现，预热不计入时延。
每个实际回合先保存，再独立物理与完整门控重放；两个实现的非计时字段必须完全一致，
包含既有提案缓存统计。只排除原有计时字段和新增证书复用计数，不放宽数值容差。
全部配对和重放完成之后才汇总实际调用时延；任何失败保存前缀并停止，不删配对。

内核检查覆盖四类动力学、强制/非强制首步、首末扰动路径、完整预测轨迹、恢复失败、
首步不合格命令和零提案缓存容量。核验所有 22 个原返回字段的数组字节及标量值、
输入未被修改、原提案缓存统计完全相同、逻辑证书子步保持一致。

此次计时是在正在使用的桌面环境下进行，每个配对只测一次；报告 pooled mean/P95、
总耗时和超过 500 ms 的调用数，不给出硬实时保证或独立显著性结论。即使小样本加速，
也不能据此修改冻结方案或宣布获得更广范围的逐状态等价性。正式预算对照仍用原实现。
