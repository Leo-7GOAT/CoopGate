# 封存课程实验的价值诊断：同指令异估值，不是因果证明

这是全部执行、物理审计和成败结论固定后的事后诊断。未再训练、未筛选策略，
也没有增加 SUMO 样本。源程序核验原完成回执内全部文件，再检查新旧策略各
500 个测试状态，共 1,000 条记录；每状态只改变一个动作坐标，探测 -1/0/1。
只有与原动作解码成逐位相同实际指令的探测才保留；其中可能包含与原动作
本身相同的重复探测，不能把探测数量理解为不同动作类的独立样本数。

原动作经过加速度和指令变化率约束；完成车辆还会执行共同的巡航生命周期。
若完整状态、执行器内态和外生扰动相同，两个提案产生相同实际指令，则当步
转移、代价、终止事件相同；接同一后续反馈策略时，真实动作价值也相同。
这是执行映射的基本一致性要求，不是新提出的通用强化学习定理。部分可观测
状态别名、不同未来反馈策略或未知执行历史，不能凭这个条件任意等同。

所有保留探测均在原不可变名义模型中重放，逐位核对下一观测、当步奖励和终止
标记一致。新策略保留 1,865 次、旧策略保留 1,237 次探测；这只是模型检查，
不是新增真实仿真执行。每个状态分别报告两个 critic 对等价探测的价值跨度。

| 描述指标 | 课程策略 | 旧名义策略 |
|---|---:|---:|
| critic1 等价动作跨度最大值 | 4.526 | 1.404 |
| critic2 等价动作跨度最大值 | 35.545 | 1.428 |
| 名义无外扰 critic1 减实际折扣回报的均值 | +7.011 | -0.732 |
| 上述误差绝对值最大值 | 10.806 | 2.347 |

回报误差仅在每角色两个名义无外扰回合、共 100 个状态上计算；这些回合所有
actor 提案均被接受，因此实际记录的后续控制就是该 actor 的确定性延续，终端
无自举，折扣为 0.99。其他动力学/扰动条件的实现回报也保存，但不冒充期望 Q。
这些状态高度相关，不能当作 100 个独立样本做显著性推断。单次最大值也不能
代表全分布的误差界。

诊断支持检验“critic 在执行无效的动作维度上产生了虚假价值差异”的假设。
它不证明这是停滞的唯一原因，也不证明执行语义一致的输入一定能改善训练。
下一项试验必须从相同未训练权重重新开始、保持奖励和真实预算，独立测试完整
任务完成情况；不能只展示等价性单元测试就宣称任务学习成功。
