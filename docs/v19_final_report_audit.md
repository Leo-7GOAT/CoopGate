# V19 最终报告的独立复算与达标判断

最终报告程序在校准选择结果产生前冻结，读取已经完整归档的校准、独立确认和实际部署回放。它不修改控制器、候选、样本量、风险阈值或原有置信区间，不读取进行中的校准分片。

## 风险、采用率和收益分别核对

对九个固定控制器，独立从逐车成本、到达时间和物理失败记录重建两种风险目标。实际随机模式每个初态只贡献一次；压力包把同一初态的四个模式合并一次。条件风险分母是实际采用过学习的初态数，零采用不能获得条件风险认证。两个目标、九个候选共用原来的 0.05 置信失败预算。

最终比较逐一复算三个训练模型的风险计数、实际采用率、收益、完成数量以及运行时间；同初态的三个模型先求平均，再按初态整体重采样，独立样本数仍为 512。所有未完成记录均保留。

原方案中的条件分别是：两种条件风险认证、实际采用率至少 20%、平均团队成本改善至少 0.5%、配对初态收益区间下端大于零。报告同时显示每个模型的四项条件与固定模型平均值。新增 `all_replicates_meet_targets` 标记要求三个模型各自同时满足条件；这是保守的汇总标记，不用某个最好的训练种子代替其他模型，也不修改原报告的平均值或区间。

收益区间仍是原来的百分位 bootstrap，均值策略改进对照仍使用原来的渐近高斯方法；它们没有因此变成新的有限样本收益保证。分场景数据仅作描述，混合分布的风险证书不会被标注成每个场景分别成立。

## 按状态选择不能直接继承固定策略的条件风险证书

假设两个始终采用学习的固定策略，各自在 100 个等概率状态中的 3 个状态发生退化，因此各有 3% 风险。两者的失败状态互不重叠。如果状态选择器恰好在各自失败的状态使用相应策略，其风险就是 6%。单独的策略风险界不能自动约束这样的状态选择器。

因此，校准结束后固定选择一个完整控制器的 LTT 对照可以继承被选控制器的证书。共形预测对照依据当前可观测初态选择策略，保留它自己的联合边际覆盖结论，不继承固定控制器的采用条件风险证书；即使最终数据恰好只选中一种策略，也不会事后改变这一规则。共形选择只读取无未来扰动的初态预测，实际模式及未来结果不能影响选择。

## 已有真实迁移数据上的复算

独立复算已经在完成的 6,400 次迁移运行上执行。60 个场景—动力学—方法组合、180 个模型分组中的采用数、退化数、完成数与平均收益，均与原报告一致，覆盖 5,760 个非基线控制器结果。这是已有数据的复核，新增 SUMO 运行数为零。

其中 2,389 个完全未采用学习的运行，其逐车成本、到达时间、命令变化总量及完成／碰撞／中止／约束结果，与同初态、同扰动和同动力学下的基线完全相同。这里证明的是归档结果一致，没有把所有未保存的原始轨迹描述为逐步一致。

这 2,389 个运行里仍有 22 个物理失败，全部发生于强执行器滞后：严格组合门控 12 个，名义门控 10 个。它们与对应基线结果相同，说明正确回退与基线在失配条件下安全是不同要求。全部 60 个非基线物理失败和 8 个基线失败都保留在复算记录中。该研究不产生失配分布下的风险认证。

证据：[`final_report_preflight/audit.json`](../artifacts/v19/final_report_preflight/audit.json)；冻结计划：[`final_report_plan/plan.json`](../artifacts/v19/final_report_plan/plan.json)。自动检查包括：重复独立样本计数、遗漏退化、跨训练模型选择、使用未来结果选策略、零采用冒充认证，以及固定策略证书的错误继承。

## 完整数据收齐后的执行顺序

继续使用已经冻结的校准、最终确认、比较与实际部署回放流程。最后追加：

```powershell
python tools/audit_final_report_v19.py run artifacts/v19/final_report
```

程序要求已提交的最终启动记录、完整数据及真实整轨迹部署回放均已存在且哈希一致，之后才建立结果目录。独立复算一致不等于研究目标自动完成；若风险或收益条件不成立，报告会保留失败项。

这些冻结阶段可以通过[连续执行流程](v19_validation_driver.md)接续当前真实校准进程，避免阶段之间等待人工启动；完整性检查、提交顺序与负面结果保留规则不变。
