# 执行器预测的等价实现优化

V32 完整在线集成显示，所有动力学/预测版本的回调 p95 均超过 500 ms。四个预先固定的合成状态调用经预热后剖析，约 99% 的门控时间进入预测核。剖析只定位开销，不构成真实仿真测时、效果验证或新的独立样本。

## 保留的计算与改变的实现

新模块继承 V32 选择器的全部初始化、执行器记忆更新、候选生成、排序、有限扰动库检查、退回逻辑和物理前提，只覆盖预测入口。预测器、原始联合规划搜索和参数验证的函数语法树与冻结原实现逐项一致，未引入去重剪枝、近似计算或 fastmath；内部模型工作计数也应保持一致。

改变发生在预测内部依赖的物理检查：采用 V25 已验证的可重复使用区间状态缓冲区，减少内层状态传播的分配。联合投影及规则后续的运算次序、平局处理、制动序列和停止判据保留。执行器增益、阻力、滞后递推和外生扰动的含义不变。

这些源级约束和已有缓冲核检查提供一致性依据，还必须通过完整的预测及真实闭环比较。正在执行的 V32 全网格实验和正式风险校准不会加载此新模块。

## 等价性与已有风险结论的适用边界

令一次物理证书在第 j 个子步前的区间状态为 `(lo_j, hi_j)`，原实现的区间更新为

\[
(lo_{j+1},hi_{j+1})=F(lo_j,hi_j,u_j),
\]

并在赋值前执行同一个 `interval_transition` 谓词。缓冲实现把同样的逐元素表达式写入另一对数组 `(qlo,qhi)`，在谓词通过后交换引用。只要所有坐标均在读取前赋值、两对数组不别名，其循环不变量为：每个子步入口的 `(lo,hi)` 与原实现完全一致，另两个数组只作为下一步写入空间。

初始状态拷贝相同，建立归纳基础；逐元素运算、谓词和交换后的状态相同，建立归纳步骤。制动尾序列、首次可停止的位置和循环上限也相同，因此返回的证书布尔值一致。在相同浮点求值规则、有效有限输入和没有内存分配等运行故障的条件下，这个论证覆盖同一求值顺序的浮点实现。它不构成跨编译器、任意 NaN/溢出输入或系统故障的机器级形式化证明。

若一次证书实际推进 N 个子步，原实现用于区间状态的数组分配为 `2+2N` 次，新实现固定为四次。减少的是反复分配与拷贝；不能据此宣称峰值区间状态存储也按同样比例下降。提前终止的短证书和完整长证书都适用同一判据。

其余联合投影、规则后续、原联合规划搜索和执行器预测保持相同运算及候选次序。逐层代入等价的证书函数后，候选、目标值、平局处理、后续状态和失败位置一致。选择器继承同一门控函数，因此在相同初态、已执行历史、外生扰动和固定决策时钟下，得到相同实际命令及整个回合结果。698 分支核验与完整配对仿真用于检查实现是否满足这些前提，不能用有限测试替代所有输入上的程序证明。

对于任意声明分布，设 A 表示回合中实际采用过学习动作，H 表示相对基线的性能退化，J 表示原成本。在上述路径级等价成立、且事件定义不使用计算墙钟的前提下，两个实现满足

\[
(A_{\rm buffer},H_{\rm buffer},J_{\rm buffer})
=(A_{\rm original},H_{\rm original},J_{\rm original}).
\]

只要 `P(A=1)>0`，便有

\[
P(H_{\rm buffer}=1\mid A_{\rm buffer}=1)
=P(H_{\rm original}=1\mid A_{\rm original}=1).
\]

这个推论说明同一控制器的等价实现应保留已有的采用事件和风险结论。当前 V32 在线执行器门控尚无新的总体风险证书，因此等价优化也没有证书可继承。若加入真实执行时延、墙钟超时回退或异步调度，命令选择和状态访问可能改变，上式不能直接沿用；需要重新验证闭环和统计条件。本节是实现等价性的论证，不是新的策略改进或风险校准定理。
