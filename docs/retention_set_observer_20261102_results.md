# 观察器保留参数但没有修复门控误判

32 单元滞后参数观察器的四项检查通过，覆盖有界扰动、速度饱和、停车、不同实际
执行指令、不一致观测及无效初始化。重放 150 条已核验的 mild/strong lag 轨迹，共
3657 个决策边界，所有真实参数所在单元及真实执行器记忆均被保留。数据只来自原
有 15 个独立初态，没有新增仿真、风险样本或控制效果证据。

保留单元数的均值约为 17.61、18.18、17.78，低于每车初始的 32 个。该集合是根据
运动观测和执行历史形成的外包参数集，不是概率后验。真实参数只在独立包含核查中
读取，没有输入预测器；预测使用固定零扰动和执行历史重构的代表点记忆。

关键负结果仍然保留：在新反例 97110131 的第一个采用时刻，每车剩余单元数为
11、25、17。保留包络下界、中点和上界的全部 27 个笛卡尔代表点，都判定候选
没有性能退化；真实系统却有匝道车到达时间增加 0.5 秒的退化。第二个采用时刻的
27 个代表点也没有报告退化。三个模型对应同一个初态、相同指令前缀，不能将其
写成六个独立场景或 162 次独立验证。

因此，观察器的参数包含性质和参数区间缩小均未证明这个有限代表点门控能识别
反例。没有将它接入在线门控，也没有称其完成修复。闭环规划及离散到达时刻对参数
可能不单调；取包络端点和中点不能覆盖中间参数的全部决策变化。本次探查为一个
选定反例上的证据，不构成这种变化机制在总体中的频率结论。
