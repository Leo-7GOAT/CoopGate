# V11 的相关工作与投稿定位

本轮文献核对截至2026年10月16日。算法与独立实验协议已经冻结，以下核对用于修正文稿定位，不改变算法、测试种子或验收标准。

## 直接相关的分层车辆规划

[Hu 等，Rolling Multi-Objective Trajectory Planning for Connected and Automated Heavy Vehicles Based on the Tolerance Lexicographic Method，IET Intelligent Transport Systems，2026，20(1):e70259](https://ietresearch.onlinelibrary.wiley.com/doi/10.1049/itr2.70259) 已将带容差的字典序方法用于车辆滚动轨迹选择，考虑效率、能耗与平顺性。作者明确说明其当前实验是基于记录交通轨迹的开环回放，周围车辆未来运动视为外生输入。因此，字典序规划或“免调多目标权重”本身不能作为CoopGate的首次贡献。

CoopGate 的当前实现使用严格整数次序，研究三辆完全合作车辆在有界执行误差下的反馈控制，将获证书基策略尾部、逐类坐标改进和指令记忆纳入同一递推。它没有覆盖上述工作的重型车能耗目标和完整横纵向轨迹任务；当前也没有复现该方法进行同预算比较。两篇工作的数值不能直接横向比较，更不能据此声称优于该已发表方法。

## 已有理论基础

[Bertsekas 的多智能体 rollout](https://arxiv.org/abs/1910.00120) 已包含逐智能体动作改进与基策略性能界；[Wabersich 和 Zeilinger 的预测安全过滤器](https://arxiv.org/abs/1812.05506) 已利用备用控制处理学习策略的约束。V11 的证明是针对具体模型和实现条件的推导，不能仅因同时使用这两类思想就称为新的通用理论。

## 当前可支持的论文表述

当前证据支持：在声明的三车合流模型中，固定指令格点、两类基控制器分别改进、字典序尾部评价与联合备用证书形成可复核的实现；名义字典序性能界、安全递归可行性以及剪枝等价性各有明确条件；独立SUMO测试检验实际扰动下的到达时间和指令变化量。

当前证据不足以支持：新的通用MARL算法、开放道路绝对安全、真实车辆舒适度改善，或相对已发表最先进方法的领先性能。投稿前需要在统一任务、信息和计算预算下复现直接相关方法，扩展车辆规模，并检验当前结论是否仍成立。
