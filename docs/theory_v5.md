# V5 完整轨迹比较与有证书的合流规划

## 研究问题

V4 已显示，联合门控 RL 可以安全完成测试，但没有超过恒定加速加同一门控。继续增加训练步数之前，需要先确定：在完全相同的动力学、动作边界、安全合同和评价指标下，是否存在明显更好的可执行方案？V5 实现一个确定性的规划教师来回答这个问题。它没有新增强化学习训练，不能将其收益记作 MARL 收益。

V4 的事后优先级审计只在主干预代价相同时改变排序。V5 改变允许让行的代价权重，并加入短暂滑行提案，随后在初始状态上预测每个候选的完整闭环执行。选择发生在真实执行前，只使用当前状态、已知模型和冻结的候选库；不读取测试结果，也不回溯真实仿真以挑选答案。

## 动力学与可恢复集合

沿用 [V4 合同](theory_v4.md)：三辆完全受控车，两条固定来路；状态包括路线进度、速度和上一加速度指令。决策周期 0.5 秒，SUMO 子步 0.1 秒。每步速度先更新再更新位置，速度限制在 0 至 20 m/s，指令限制在 −5 至 2.5 m/s²，指令变化不超过 2.5 m/s²。

同来路车头间距至少 6.8 米；不同来路的车辆不能在同一子步时间内共同占据冲突区 [−25, 6.8]。双方进入保护范围后，还要满足路线坐标间距。子步内部按仿射插值精确计算占区区间及最小间距。

备用递推为

\[
B_i(u_i^-)=\max(-5,u_i^- - 5\Delta).
\]

记扩展状态为 z，K_B 为执行 B 可安全停止的集合。接受动作 u 的条件为：满足指令边界与变化约束，首个决策周期安全，随后执行 B 的联合轨迹安全到达静止终端集合。V5 的批量检查对每个候选保留各自的状态和指令记忆，与 V4 标量检查逐项对比测试。

**性质 1 有证书的候选轨迹。** 若 z₀∈K_B、模型精确且车辆服从指令，则每次从通过认证的模式中选取动作，可以保持路线合同和后继状态的可恢复性。

证明：当前状态属于 K_B 时，全备用是可行候选。任意被认证的首步具有安全首步和到达终端的备用尾部，因此后继状态仍属于 K_B。指令记忆使尾部与下一周期的备用递推一致。对每个规划步骤归纳即可。V5 没有为更高通行效率放宽证书或修改冲突区。

这不是一般道路的安全定理。该基准没有背景车、自由换道、观测误差、未知执行器扰动或内部路口连接；路线合同不等于任意车辆外形在连续空间中的防碰撞证明。

## 有限候选库与完整到达代价

候选 0 是冻结的恒定加速门控，包含完全一致的干预代价与平局处理。另有 36 个反馈方案：三个次序偏好 (0,1,2)、(0,2,1)、(1,0,2)，三个权重比 r∈{2,8,32}，四个初始滑行时长 q∈{0,2,4,6} 个决策周期。

按次序排列的权重为 (r²,r,1)。初始 q 个周期内，非首选车辆提案为零加速度，其余时间提案为最大加速度。已完成车辆恢复统一巡航提案。所有提案都先投影到指令变化约束，再在“提案／备用”的八种联合模式中认证，选择加权平方干预最小的模式：

\[
u_k^j=\arg\min_{u\in\mathcal F(z_k^j)}
\left[\sum_i w_i^j(u_i-p_i^j)^2-10^{-8}\sum_i u_i\right].
\]

这里次序只是偏好；安全证书可以否决该次序偏好产生的指令，不保证最终车辆通过次序与偏好相同。全备用保证模式非空。

对每个方案进行模型内闭环展开，直至全部完成或达到 25 秒截止时刻。主目标为

\[
J_j(z_0)=\frac{1}{3}\sum_{i=0}^2\min(T_i^j,25),\quad
j^*\in\arg\min_{j=0,\ldots,36}J_j(z_0).
\]

未完成车辆计 25 秒，已完成车辆记录首次到达 s≥60 的决策时刻。目标是平均到达时间，不是全车最晚到达时间，也不包含 jerk 或能耗，因此还要单独报告这些代价。真实执行发生碰撞时，该回合所有车辆计 25 秒。

**性质 2 精确模型下相对保留基线不劣。** 若当前模型与执行一致，初态相同，生命周期和到达代价相同，并且完整计划被执行，则 J_exec=J_{j*}≤J₀。

证明：方案 0 属于比较集合，取最小值不会高于 J₀。由模型与执行一致，所选轨迹在执行中具有相同到达时刻。证毕。这是保留基线的有限方案比较性质，不是新的普适最优性定理，更不意味着对所有控制序列全局最优。平均代价不劣也不蕴含每辆车都更早到达。

两个消融明确区分候选内容和比较目标：

1. **短期选择**：同一 37 个方案只按前 2 秒的截断位置和排序，然后执行选中方案的完整轨迹。它是固定方案选择消融，不是滚动时域 MPC。实现仍展开完整轨迹用于证书记录，不用其运行时间声称短期规划更快。
2. **无提前滑行**：按完整到达代价选择，但只保留方案 0 与 q=0 的九个加权方案。

## 缓存轨迹与运行时退出

规划器保存所选方案每步的期望状态、上一指令和执行指令。执行时逐步比较实测状态与期望状态，并重新认证当前首步；计划不匹配或证书未通过，则永久退出该缓存计划，改用原始反馈门控。

因此缓存不是绕过安全检查。另一方面，退出后的执行轨迹不再等于原预测，性质 2 的效率保证随之失效。若扰动把实测状态带到 K_B 外，原备用也没有本项目声明的保证；不能把检测到偏差后回退等同于鲁棒控制证明。单元测试使用仍在 K_B 内的状态偏移验证退出机制。

记录首次规划时间、后续每周期执行时间及二者之和构成的首次响应时间。仿真在规划期间不推进，测得的用时不能替代有计算延迟的动态系统证明，也不是最坏执行时间保证。按照项目要求，不引入通信延迟指标。

## 与前人的关系与下一步学习问题

[Multiagent Rollout Algorithms and Reinforcement Learning](https://arxiv.org/abs/1910.00120) 已讨论多智能体 rollout 与相对基策略的成本改进性质。[DMPS](https://arxiv.org/abs/2405.13863) 已通过恢复规划结合短期进展和长期收益，处理安全屏障妨碍任务推进的问题。[On-Line Policy Iteration with Trajectory-Driven Policy Generation](https://arxiv.org/abs/2604.15004) 进一步研究固定初态下轨迹驱动策略改进和一致性条件下的单调成本改善。因此不能将“完整轨迹比较”“保留基线不劣”或“规划教师帮助学习”本身作为首次创新。

V5 的贡献是一个可执行的对照：相同安全合同下，提前协调能够提供多少学习机会，局部进展目标会损失多少，以及完整比较需要多少计算。若实测收益成立，后续学习目标可以从模仿恒定加速改为学习次序和让行时机，并同时考核相对完整规划器的代价差、计算成本和失败回退。应新建训练集、验证集和测试集，不能用本次 80 个测试场景训练后再宣称泛化。

后续若提出“置信度”，必须区分轨迹可恢复性的布尔证书与预测性能的统计可信度。单个网络分数不能同时证明这两者。目前尚未实现学习式性能置信度或不确定模型下的鲁棒证书。
