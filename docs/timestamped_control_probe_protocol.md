# 时间戳观测补偿的完整闭环开发对照

该开发检验“已验证的定位估计能否改善已知闭环失败”，不替换冻结的风险、公平预算、
候选 factorial 或完整 OOD 队列。只使用已完成 V45 的三个旧初态和十三种方法/模型，
共三种预处理 × 三条件 × 十三方法 = **117 次真实 SUMO 执行**，新增独立初态为零。

## 固定预处理与共同信息

1. projected_raw：原 V45 速度投影，位置不补偿；
2. constant_velocity：位置增加测量年龄 × 投影速度；
3. envelope_midpoint：取已冻结时间戳/命令历史状态区间的中点。

所有变体都形成相同的公共状态区间，并可用同样的测量来源时间戳、公开测量误差和
组合动力学外包络、实际历史指令。不同的是送给旧控制器的点状态。旧 V35 控制器、
学习权重、阈值、lag_strong 内部预测和执行流程不改，不以中点估计冒充精确真值。
物理证书适用性仍为 false，不能声称中点处理恢复其假设或提供安全停车保证。

传感器端只向公共端口发布 profile、当前决策序号及每车来源时间戳，控制器只持有
该端口，不持有环境、传感器对象、真实参数、内部记忆或未来创新。传感器原观测及
其证据保持不变。公共区间由过去命令及当前接收测量计算，不读取真值修正估计。

三个已知开发点分别为 seed 139886001（mild/clean）、139886002（heterogeneous/
bias_jitter）、139886003（severe/stale_dropout）。场景、执行器与观测在这些点上
同时变化；只能比较每点内部预处理差异，不能分离观测类别的平均因果效应。
沿用全部三个固定学习模型和十三方法，不按新结果删方法或选模型。

## 完整执行、配对与独立审计

先提交实现、协议、所有审计及检查，再独占 freeze，提交协议后启动 run。9 个区组
按变体顺序与旧开发点顺序执行，每组完整十三方法。原生退出采用真实 Windows 句柄
观察，收到 0 和完整 117 范围后，才运行已冻结的全量审计并生成结果。

每个回合先持久化 SQLite，再独立重建感知、FIFO、执行器、物理子步及控制器。
每次调用还记录原观测、公共时间戳、估计区间、中点/其他处理输入及异常，包含首次
采用前失败和最后中止调用。审计使用旧函数体的私有依赖映射独立发布重建的时间戳，
重新执行预处理及门控；没有改动任何旧模块全局。原传感器/物理审计仍必须全部通过。

projected_raw 的全部 39 回合须与已封存 V45 的所有非计时原字段、动作和轨迹完全
一致；仅忽略明确新增的预处理/速度投影说明以及原计时字段。该条件失败是接入或
复现问题，应保留前缀并停止，而不是删除控制组或修改比较标准。

真实控制器异常、超时未完成、碰撞和几何违规均保留。工程估计器异常也保留公共输入
和错误，不重置以隐藏失败。若独立审计不一致，保存未封存前缀并停止，不隐式重启。
单条件配对收益仅在该方法和它同变体基线均成功时报告。每个控制器跨三开发点的完整
范围收益，只有全部三点的方法及配对基线均成功才计算；任一点失败即为空，不以成功
子集重新生成总体收益。

## 资源及结论范围

与现有正式采集共享桌面资源，Torch 固定一线程，SUMO 在计算时等待。不施加回调
截止，也不进行隔离延迟或 WCET 排名；V44/factorial 的安静运行要求原样保留。
新增源码与输出独立，不改正在运行的正式源码、数据、采样或推断。

本研究是选自已知失败的三个旧初态上的开发消融，没有独立总体风险检验。它不证明
MARL 训练、方法族优越性或一般分布外可靠性。即使任务完成改善，也须进一步处理
整个状态区间和执行器模型失配，不能自动升级为原物理或统计证书。
