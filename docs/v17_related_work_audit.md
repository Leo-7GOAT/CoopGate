# 门控相关工作补充核查（2026-10-16）

以下核查依据原论文摘要、正式论文页面与作者公开材料，尚不是完整系统综述。它约束本项目可以提出的创新表述，不能当作已证明超越这些方法。

| 原始工作 | 已有贡献 | 对本项目的限制与可比较点 |
|---|---|---|
| [MA-COPP，CDC 2024](https://arxiv.org/abs/2403.16871) | 在一个或多个智能体改变策略时，处理其他智能体轨迹分布随之变化的离策略共形预测；构造联合轨迹区域，并在 PettingZoo、F1TENTH 评估 | “多车策略变化需要联合校准”不是首创。本项目当前对每个冻结完整策略直接重新采集配对仿真数据，预测的是相对基线的逐车成本/时间差，没有实现从旧行为策略数据迁移到未运行的新策略的密度比校正。 |
| [Multi-Agent Planning with Baseline Regret Minimization，IJCAI 2017](https://www.ijcai.org/proceedings/2017/63) | 在有限时域 Dec-POMDP 中最小化相对给定基线的遗憾，并给出非退化策略规划结果 | “多智能体相对基线改进”本身已有充分先例。当前神经近似联合训练不继承该文的精确策略规划保证。 |
| [CSPI-MT，2024](https://arxiv.org/abs/2408.12004) | 针对阈值策略，使用校准检验和多候选检验寻找相对基线的可靠改进，同时处理检验功效不足导致频繁退回的问题 | “置信阈值切换、多个候选、在可靠性下提高采用率”不能作为独立首创。本项目还需要把交通交互、逐车退化和实际物理接管的效果做实。 |
| [Deep SPI，ICLR 2026](https://proceedings.iclr.cc/paper_files/paper/2026/hash/0212b0dff7b4aa3bd8b8cc4ce24fd384-Abstract-Conference.html) | 将世界模型和表征学习纳入安全策略改进，分析受限策略更新邻域与单调改进，并提出 DeepSPI | 不应把 V16/V17 的模型式近似策略迭代宣称为新安全 RL 理论。本项目使用已知纵向模型，尚没有世界模型学习误差的同类证明。 |
| [AdaptNC，2026 预印本](https://arxiv.org/abs/2602.01629) | 联合调整非一致性分数和阈值，应对策略、环境与传感变化，并评估多智能体变化场景 | 本项目当前使用冻结预测器、独立初态簇与固定分组，不宣称任意在线变化下有效，也不能把换一个残差尺度称为首创。 |

本项目应围绕一个可检验的具体问题组织论文：在同一交通动力学与物理过滤器下，完整联合策略的性能门控，能否比逐车独立选择更可靠地保留实际学习收益，并在预测不足或运行故障时退回可执行基线。需要实际实现独立门控、完整联合门控、常开学习、始终基线及学习算法对照；目前的事后机制反例和开发诊断还不能替代这些正式实验。

尚未证明顶刊或顶会级别的新颖性。若最终贡献只是把已有联合预测、共形界和安全过滤器相连，方法创新可能不足；必须凭可复现的交互问题、明确且合理的假设、有效采用率与净收益、以及工程闭环证据来评价投稿价值。
