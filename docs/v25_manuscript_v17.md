# 第十七稿的证据范围与文档核验

桌面第十七稿沿用第十六稿的结构和排版，将已完成的共同统计口径对照、完整门控计算改进和条件风险迁移推导写入正文。它是研究工作稿；正式风险校准与全范围加速验证仍在运行，稿件没有使用这两项研究的部分效果，也没有新增风险认证结论。

第20节报告历史九候选在相同LTT规则下的全部风险上界、独立最终收益、采用与退化计数，明确整组交并检验与可选择候选的多重检验不是相同命题。历史数据只支持严格门控1812同时通过两个目标，不能据此认定新门控的完整模型组已经通过。

第21节报告一个旧初态、三模型、四模式的24次实际SUMO配对验证。完整门控耗时减少75.423%，所有非计时输出一致；仍有8/277次决策超过500 ms。该组结果与原完整开发集的时延分开陈述。6,912次全范围实现验证标记为进行中，记录全部原失败和终止异常调用耗时。

第22节给出采用后条件风险对事件分布总变差的敏感性推导，明确正采用概率、有效总体界和联合置信预算等前提。它使用标准总变差工具，不宣传为新的统计理论。完成的270个匹配迁移单元用于解释边界；经验TV、有限回放零差异和20%经验采用率均不被写成总体置信保证。五类场景中的负收益、低采用分母和强惯性失败保留在正文中。

## 文档检查

最终Word文件为28页，原23个可编辑OMML公式及20张表逐项保留，新增5个可编辑公式、两张表和两幅已有实验图。原样式、主题、编号和节属性保持一致。两张新表的全部九行对照与五行计时数字再次同已完成JSON报告核对。
