# CSPI 作者流程的小规模开发复现协议

目的：把已有原函数契约检查推进到实际数据生成、阈值选择、留出测试和部署选择的完整
数据流。不是 CoopGate 性能实验，不代替正式公平对照，也不复现原论文的错误率曲线。

固定作者提交 `b5af605a38a7866c52745c153e02cb4bf049ea01` 的
[Figures_2_and_3_for_KDD.py](https://github.com/facebookresearch/CSPI-MT/blob/b5af605a38a7866c52745c153e02cb4bf049ea01/Figures_2_and_3_for_KDD.py)，
Git blob 为 `84323a8cf90351cf69fbbc59300523ddca54f625`。仅加载其 13 个原始函数定义，
函数体不更改，顶层循环与绘图不执行。所有第三方代码保留在仓库外，仅发布我们编写的
驱动与实验数据、记录。

运行前提交本协议和驱动。固定三种原始 DGP：线性效应、roof、常数 -0.25 效应；每种
只执行一次，seed=42，2000 调优样本、8000 测试样本，误差参数 0.05，50 个候选阈值
`linspace(2,-1.9,50)`，基线阈值 -2，10000 个高斯模拟抽样、五折结果模型。
不按结果删 DGP、修改阈值、重抽种子或增加“直到通过”的重复。

保留原调优函数返回的四种单阈值规则、两种多阈值规则，以及两个 HCPI 对照和 naive，
共每种设置九条输出。多阈值只在通过测试的候选中，按原驱动的全样本价值估计选择；
无人通过时部署基线。不同方法共享数据，27 条输出不是 27 个独立统计重复。

原脚本先在整批样本上交叉拟合结果模型，再划分调优和测试行。这里忠实保留这一数据流，
但明确记录：调优和测试的观察行不重合，结果模型的拟合折来自整个数据集；不能声称
所有辅助模型都由完全独立的调优样本训练。原脚本中 HCPI 的固定常数及计算公式也
保留，不给它们添加额外有效性声明。运行环境单独建立并记录精确包版本，不改变
CoopGate 正式冻结实验的 Python 环境。

独立校验用阈值指示函数之差乘以双稳健处理效应分数，计算点估计和协方差，要求与
原 PDE 对全部 50 个候选一致。检查原始连续分数是否恰好等于阈值；若有，保留失败并
停止，而非抖动分数或删样本。之前识别的离散端点问题仍不被掩盖。

保存每个 DGP 的完整输入数组、方法选择和测试结果，以及已知 DGP 下的真实平均价值差。
真实价值只用于事后检查，不反馈给选择器。常数负效应 DGP 下基线为 treat-all，减少
处理可能改善其价值，因此不能把“负处理效应”直接称为“所有候选均劣于基线”。

任何通过或失败只表示这个固定开发样本的原流程输出；一次抽样不能验证 5% 错误率，
更不能证明车辆物理安全、单车/多车收益或正式门控风险。正式接入交通实验仍需明确
完整回合为单位的处理分配、评分信息、预算、保留数据与检验目标。
