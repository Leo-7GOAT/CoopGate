# 周期内到达时刻：全准入状态诊断

当前评价在每个 0.5 秒决策周期结束时登记到达，物理积分步长为 0.1 秒。两条轨迹可能在同一决策周期被登记到达，但跨越终点的先后不同。本诊断增加周期内到达时刻这一观察量，保持原始动力学、强反馈基线、成本、终点、控制周期及全部历史指标不变。

## 定义与有限路径逻辑

在一个 0.1 秒物理步内，设位置由 p^- 变为 p^+，且 p^- < p_goal <= p^+。用该离散模型步内匀速运动的线性插值定义事件时刻：

```text
tau = t_before + dt * (p_goal - p^-)/(p^+ - p^-)。
```

它精细化的是当前仿真离散模型的过线时刻，不等于证明连续真实车辆模型准确。对于完成的车辆，以共同决策时刻为起点，原登记时间满足 T = h ceil(tau/h)，h=0.5 秒。因此 tau_candidate <= tau_baseline 蕴含 T_candidate <= T_baseline；反向蕴含不成立。当原登记时间严格改善至少一个周期时，该分量的插值时间必然也改善。额外检查主要区分原来登记时间相同的分支。

若未来控制器在每次准入时，对每条固定路径都检查完整的“当前联合动作后续跑同一基线”的插值到达时间，可定义剩余插值到达时间势函数 V_b^tau。车辆尚未到达且本周期不过线时，阶段时间为 h；本周期过线时为周期内实际事件时间；已到达车辆为零。于是：

```text
delta_tau = stage_tau + V_b^tau(next) - V_b^tau(current)。
```

在模型精确、同一完整扰动路径、完整状态与时钟、完成及终端条件成立时，逐步 delta_tau <= 0 可望远镜求和为整段插值到达时间不退化，进一步得到登记时间不退化。共同基线动作的势差为零。原成本分量仍须单独检查；更细的到达顺序不能替代控制变化量成本约束。

这里的结论限于共同模型和被完整检查的路径。它不能覆盖任意库外扰动、预测故障、未完成分支或动力学失配，更不能自动产生总体风险证书。

## 冻结诊断范围

程序遍历完整 1,536 次动作调整运行中的全部 526 次准入，覆盖有害与无害轨迹、三个模型和四种模式。对每个不同状态/前动作/当前动作/时钟组合，重算同一 33 条路径的基线与候选：

1. 新预测器输出的原成本、登记到达时间差必须匹配原存档。
2. 额外记录所有车辆的插值到达时间差，全部不大于 1e-10 才通过；未完成预测不能通过。
3. 完成上述判断后，才用实际未来扰动标签解释单步后续跑基线的正/非正残差。

最后一步属于事后机制分析，实际未来扰动不进入前两步。诊断不修改控制器或重跑闭环；拒绝一次动作会改变未来状态，因此存档中保留的准入次数不能写成新策略的采用率，局部分支识别率也不是总体风险。

实现为 [arrival_phase_v20.py](../src/coopgate/arrival_phase_v20.py)。五项测试已验证插值对同一登记周期内顺序的区分、三种扰动下原预测指标一致，以及未完成预测保留缺失到达时刻。[诊断计划](../artifacts/v20/arrival_phase_screen_plan/plan.json)已冻结。结果需在原运行进程终止并核验后报告，任何新控制器仍需完整闭环开发及新的独立校准。
