# 在线执行器门控的完整迁移对照

固定的 120 次 SUMO 集成已经完成，并通过独立轨迹、在线输入和准入记录复核。强滞后组的名义预测版本有一次采用后性能退化，参考执行器版本没有出现；其余部分条件下参考版本更保守、收益更小。这些结果来自五个共享旧初态，不能据此选择表现最好的模型、宣称总体风险达标或只扩大有利场景。

完整扩展保持两个控制器及三个训练模型原样，覆盖原五类场景、四种动力学、每场景 32 个初态，共 160 个不同旧初态、640 个初态/动力学条件、3,840 次真实 SUMO 执行。包括集成阶段出现过的 120 个条件，全部重新运行；重复执行不增加独立样本数。场景和模型均不根据集成结果删减。

## 公平比较的具体条件

- 两个新版本共用学习策略、候选组合、33 条固定外生扰动路径、逐车原成本/到达指标、50 ms 相位条件、物理检查和传统回退。
- 参考执行器的类别系数预先指定；不读取每回合真实随机参数、隐藏执行器状态或未来扰动。名义版本使用名义执行器递推。
- 初始状态、随机动力学参数、外生扰动路径及其指纹与原基线/历史 phase05 逐项一致。
- 两个新版本的执行先后按固定配对索引交替。状态访问、候选排序和搜索工作量可能不同，不能把这些对照描述为严格等计算预算。
- 历史 phase05 的扰动库和实现不同，仅作保留的历史对照。新版本之间的消融才能直接定位执行器预测模型的影响。

## 失败和测时规则

每个初态/动力学条件独立封存六条记录，覆盖三模型、两版本。执行器失配越过原 ±0.5 m/s² 条件、控制器中止、基线失败和零采用均保留。

原成本仍为各车到达时间加 0.05 倍指令变化量；未到达车辆保留原时域上限，不改写评价指标。任意配对不完整时，该汇总单元的全范围相对成本改善标记为空；完整配对的改善另列为描述性结果，并同时报告分母和失败数。基线不完整时，不把较低记录成本解释为性能提升，也不计算一个虚假的相对性能退化标签。候选失败而基线完整时，失败明确计入有害结果。

计时包裹整个 select 调用，包含抛出终止异常的调用。独立复核必须同时检查成功和失败调用、全部真实动力学轨迹、参考状态递推及实际准入证据。全部 640 块完成、真实工作进程退出为 0 后才生成完整比较报告。

这是原迁移网格上的开发比较，不能替代新的独立确认、风险校准或更广路网验证。正式校准继续执行冻结的原方案；本扩展不读取其未完成结果。
