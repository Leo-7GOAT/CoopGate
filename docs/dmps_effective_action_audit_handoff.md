# 当前原生训练进程到冻结审计器的一次性衔接

训练、测试和科学审计源码均已在启动前固定。本新增辅助程序只接管执行完成的
观察与审计衔接，不改变训练、指标、测试案例或审计通过标准。

2026-10-25 09:53:48 UTC，辅助程序已在原生训练进程 11184 仍存活时打开并保留
Windows 进程句柄。核验了原记录的父进程、实际训练命令和创建时间；创建时间
为 09:31:17.035507 UTC，与原启动记录一致。保留的句柄绑定实际进程，不会因
稍后 PID 重用而误认其他任务。独立观察文件保存在正在采集的目录之外。

辅助程序等待实际原生进程退出，再读取 GetExitCodeProcess。仅实际退出 0、
完整完成回执、原协议/启动身份及全部声明训练/评估数量吻合时写成功退出证明，
随后调用早已冻结的全量审计器。非零退出保留实际退出码并停止；没有完成文件
不算成功。它不按观察超时重启原任务，也不依赖“进度 100%”判断完成。

两项检查通过：PID/父进程/命令/创建时间不一致会被拒绝；非零退出和不完整
测试数量不能触发成功审计。实际原生句柄已附着，尚在等待原训练完成，不能据此
提前宣称科学审计或策略修复成功。此为单次本地执行链，没有创建周期调度任务。
