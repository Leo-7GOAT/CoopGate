# 相同数据之外：把门控效果与统计命题分开比较

此次补充仅检查对照的可解释性，重现已完成V19研究的既有结果。正在运行的V21校准没有做部分效果分析，主门控、候选、采样预算、检验水平及最终验收规则均未改动。新的报告入口只有在完整校准、最终确认和实际进程退出凭据均通过后，才允许读取V21的结果。

## 相同的多重检验负担

主命题要求一组内三个固定模型的两个风险目标全部达标，使用不可拆分的交并检验。LTT部署选择器则可以在九个完整控制器之间选择，因此既有实现对可选择的九候选进行Bonferroni校正。相同的校准数据不意味着这两种命题具有相同检验负担，不能把主命题更容易通过直接解释为门控更可靠。

补充表完全复用已有的两套LTT输出：实际模式目标和四模式组合目标各使用0.025错误预算，每个候选/目标的检验水平均为0.025/9。原始学习、名义门控和严格门控的九个候选全部使用该规则，不重新计算一个更宽松的证书，也不按最终表现选训练模型。这是[LTT的条件二项检验和多重检验思想](https://arxiv.org/html/2110.01052v5#S3.SS2)在本任务中的固定适配。

一个不含实验数据的例子说明差异：同样是100次采用、零退化，固定整组在0.025水平下的最大风险上界约为3.62%，可以通过5%目标；可选择候选在0.025/9水平下的上界约为5.72%，未通过。同样零退化时，两个程序分别至少需要72和115次采用。数据和控制器没有改变，变化来自允许报告/选择的命题。计算和正在运行时的拒绝读取检查见[核验记录](../artifacts/v25/comparison_scope_checks/verification.json)。

## 已完成历史数据支持什么

[九个控制器的完整共同规则表](../artifacts/v25/historical_common_inference_audit/report.md)同时报告校准风险上界与独立最终收益、采用率和经验退化。两批数据不混用，旧证书不被最终较好的表现追溯修改。

V19名义门控的最终成本改善为1.47%—1.72%，采用率66.4%—72.7%，但校准实际风险上界仍为18.9%—21.1%。严格门控的成本改善为0.67%—0.72%，采用率20.9%—22.3%，实际风险上界为4.29%—5.03%，组合风险上界为3.88%—8.08%。这体现风险、收益与采用率之间的取舍。使用完全相同的既有LTT规则，只有严格门控的模型1812通过两个目标；三个控制器族均没有达到全模型通过，结论与原报告一致。

这些是历史已完成研究的数字，不是正在校准的phase05结果。主方法今后的整组证书与同规则对照表应并列报告：前者回答预声明的整组要求是否满足，后者避免将较少的多重检验负担误当成算法收益。

## 三种“置信”不能互换

令C是随机校准数据、Z是新初态及其扰动，A表示实际采用学习，H表示任一车辆性能退化或执行失败。采用后的风险是r=P(H|A)，当P(A)=0时未定义。

1. 本项目的精确二项检验控制错误认证的概率：对一个固定不合格策略，校准数据使它错误通过的概率不超过预先分配的delta。它不提供某个当前状态的“97.5%可行概率”。
2. 这里的split-conformal适配提供校准数据和新初态共同随机性下的边际覆盖。[标准共形覆盖](https://arxiv.org/html/2107.07511v6#S1)不自动给出固定校准集上采用后的条件风险保证。即使已知联合边际P(A且H)不超过alpha，也只能在同一概率空间、P(A)>0时推出P(H|A)不超过alpha/P(A)。不能把有限测试集的经验采用率直接代入，冒充新的高置信风险证书。
3. Mean-SPI适配检验总体平均团队收益，不能推出每辆车均不退化或采用后风险低于5%。其来源是[CSPI-MT的联合均值检验](https://arxiv.org/html/2408.12004v1#S4.SS3)；本项目有完整配对仿真结果，没有复现原文观察数据的双稳健估计和阈值搜索，联合高斯近似也不是有限样本精确保证。

物理备份可行性还依赖初态处于可恢复集合、扰动界和执行器模型等假设；它与上述性能风险是不同层面的结论。强惯性失配超界时，本项目不延伸这些保证。

该补充新增仿真次数和独立样本数均为零，不是新算法或新风险认证。已有主分析和未来最终验收不被本报告替换。
