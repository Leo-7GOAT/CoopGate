# 自车收益与双指标性能门控：独立 SUMO 验证

**主体已改为自车。** 所有到达时间和指令变化量主指标都属于学习车辆，变化量仅累计到该车到达；另外两车的平均时间另行报告。

实验在提交3bac214冻结后运行：128个独立初态×四类误差×14种控制器，共7168次实际SUMO执行。校准另有256个独立初态、1024次执行。三个全新训练种子各进行2097152步Double DQN模型训练，均保留最终检查点，没有模仿标签。

**两种学习执行方式分别报告。** 纯网络直接提案；学习辅助规划器使用网络给出额外的未来反馈序列，在线规划器再选择动作。不能将后者的结果写成纯RL优于基线。

相对强规划基线，学习辅助规划的自车代价降低3.199%，自车到达时间降低2.627%，指令变化降低19.280%。相对同构未训练网络对照，代价降低3.143%。

门控代价降低2.314%，到达时间降低2.028%。纯网络前置检验：未通过；MARL扩展继续保留阻断条件，不把辅助规划器的成绩替代纯网络成绩。

## 门控保留收益和过滤退化

门控要求成本改善上界≤−0.05秒、到达时间差上界≤0秒。两维残差最大值统一校准，性能门控在一次合流开始时执行一次，安全证书每0.5秒复核。

|初态分组|策略回合数|放行率|有害放行占全部|放行后退化率|保留净收益|经验联合覆盖|
|---|---:|---:|---:|---:|---:|---:|
|全部|1536|12.24%|1.11%|9.04%|72.33%|93.68%|
|低冲突|468|0.85%|0.00%|0.00%|15.25%|97.86%|
|高冲突|1068|17.23%|1.59%|9.24%|73.67%|91.85%|

有害指成本或自车到达时间中任一项退化。低/高冲突按初态ETA差1.25秒预先划分，不能等同于任意简单/复杂道路。策略回合数包含三个模型和四类误差重复；独立初态数为128。

共形界针对可交换回合的边际风险，不是碰撞概率，也不是放行子集的条件错误率保证。经验联合覆盖率照实保留，不能为了接近90%而调整已冻结阈值。

未校准成本门控与仅成本校准门控用同场景已执行的完整轨迹重组，不计作额外SUMO运行。双指标门控本身另作实际执行，并检查其轨迹与选中控制器一致。

|门控消融|放行率|有害放行占全部|保留代价收益 s|
|---|---:|---:|---:|
|uncalibrated_cost|20.83%|2.15%|0.2539|
|calibrated_cost_only|13.54%|1.17%|0.2318|
|joint_cost_time|12.24%|1.11%|0.2262|

与仅成本校准相比，联合时间约束将本批有害放行从18次降到17次；额外减少幅度有限，同时少保留了一部分收益。双指标的价值首先是约束含义清楚，当前数据不足以证明它显著优于仅成本校准。

## 统计与工程边界

配对bootstrap以初态为簇，先平均四类误差和三个固定模型，再重采样10000次。95%区间是近似描述性推断，不代表训练随机种子的总体保证。每个模型的指标、原始失败、计时和完整核验材料均在summary.json及study/中。

只验证固定路线、精确状态、三辆全受控车辆与已知误差界。共同安全层能够制动规则车辆；这不是非合作开放交通。未统计通信延迟，未做实车与真实延迟闭环。
