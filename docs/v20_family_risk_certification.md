# 三份固定模型共同认证：前瞻统计设计

当前目标要求三份固定模型的实际扰动风险及四模式组合风险全部达标。可以直接检验这个整体命题：只要六项中任何一项未通过，就不认证该组策略。该结构是既有的交并检验（intersection-union test，IUT），不是新的统计定理。相关原始文献为 Berger 与 Hsu (1996), [Bioequivalence Trials, Intersection-Union Tests and Equivalence Confidence Sets](https://doi.org/10.1214/ss/1032280304)。下面给出本任务的自包含推导。

此设计不改变原 V19 校准结论，也没有对已读过的开发数据重新发证。该版本的代码和功效计算属于前瞻工具。后续 [V21 验证规则](v21_prospective_validation.md)已固定 4,096 个新校准初态与跨轮错误预算，但具体完整策略组仍待开发实验完成后选择，新校准尚未开始。

## 固定总体、采用事件与风险

在新的独立同分布初态及预先声明的扰动生成机制下，固定模型、门控、候选族和统计规则。对六个目标中的每个 j，令 A_j 为采用事件，H_j 为采用后的逐车退化事件，定义 r_j = P(H_j=1 | A_j=1)。组合目标以一个初态及其四模式整体为一条样本；不能把四种模式作为四条独立观测。

若采用概率为正，固定总初态数并按上述方式独立采样，则条件于采用数 N_j，退化数 K_j 服从 Binomial(N_j, r_j)。不同目标可以强相关，证明不要求目标之间独立。N_j=0 时条件风险未观测，程序返回 p=1、上界=1，不能认证。

设性能风险阈值 alpha=0.05，组内允许的错误认证概率为 delta。检验 H0j: r_j >= alpha 使用精确下尾 p 值：

```text
p_j = P[Binomial(N_j, alpha) <= K_j]。
```

## 整组错误认证控制

整组零假设为“至少一个目标风险达到或超过 alpha”，即六个 H0j 的并集。仅当所有 p_j <= delta 时通过，等价于 p_family = max_j p_j <= delta。

若整组命题为假，总有一个由真实总体确定的 j* 满足 r_j* >= alpha。整组通过事件包含于该目标通过事件，所以：

```text
P[错误认证整组] <= P[p_j* <= delta] <= delta。
```

这里不需要对组内六项再作 Bonferroni 分摊，因为报告的是全部同时通过这一不可拆分命题。若试验失败后丢掉某个模型或目标、只报告余下部分，就改变了命题，不能使用这个论证。

还可为每项计算单侧 Clopper-Pearson 上界 U_j，置信水平为 1-delta，取 U_max=max_j U_j。令真实最大风险 theta=max_j r_j，对一个总体确定的最大风险目标 j*，有：

```text
P[U_max < theta] <= P[U_j* < r_j*] <= delta。
```

因此 U_max 是六个固定风险最大值的一个有效共同上界。各个 U_j 本身仍只有逐项覆盖率；不能宣称这些较紧的单项上界具有联合覆盖率。代码同时检查 p_family 和 U_max，边界数值差异只能使决策更保守。

若预先声明 F 组不同策略族，并允许校准后选择其中一整组，则每组使用 delta_total/F，再对 F 组作联合界。这允许选择完整通过的一组，不能跨组拼接表现较好的模型。策略、分组、样本量及所有选择器必须在新校准数据生成前冻结；不允许按结果追加样本直到通过。

## 与原方案的区别及功效

原方案为 9 个候选各自的两项风险提供可分别选择的证书，使用 0.05/18 的水平。它允许更细粒度的选择，原方案没有错误。新方案放弃组内挑选，匹配“所有三个固定模型、两项风险均合格”的要求；它不会降低真实风险或补救不合格的控制器。

| 命题结构 | 每个构成检验的水平 | 零退化时最少采用数 |
|---|---:|---:|
| 原 18 个单独命题 | 0.05/18 | 115 |
| 预声明 3 个完整策略组 | 0.05/3 | 80 |
| 只预声明 1 个完整策略组 | 0.05 | 59 |

以下为前瞻假设：六项目标的采用概率都为 20%，条件风险都为 2%。表中是六项全部通过概率的保守下界，由各项精确功效与联合界计算；不假设六项独立。

| 独立初态数 | 原 18 单项程序 | 3 个完整组之一 | 1 个完整组 |
|---|---:|---:|---:|
| 1024 | 0 | 0 | 0 |
| 2048 | 0 | 0.1001 | 0.6740 |
| 4096 | 0.8099 | 0.9723 | 0.9953 |

下界为零不代表通过概率为零。上述六项相同边际是假设情景，实际模式与四模式组合的采用率、风险通常不同。功效只针对风险认证，不包括采用率至少 20%、收益至少 0.5% 或独立收益区间为正等要求。真实风险若超过阈值，扩大样本不能使它成为合格策略。
