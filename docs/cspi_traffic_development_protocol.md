# CSPI 原作者统计流程的交通回合接入开发协议

本协议在运行接入之前提交。输入为已经完成并公开检查效果的 V36 网格报告，SHA256
为 `1e13918534046bc71b3a39a0ee340c5852357778930dc5cbc8b96cf4eb175162`。
因此它只验证接口和数据隔离，不构成盲测、新独立样本、原论文实验复现或正式优越性证明。
不读取运行中 V32 或任何正式校准/确认的中间效果，不改变已有冻结方案。

## 处理单位与公平性

独立单位取旧网格中的 160 个原初态；模型、动力学、控制步不能扩大这个数量。
每个原初态用固定 RNG seed 804600 从四类动力学中选一种，再以 0.5 概率分配处理。
处理 0 是完整共同恢复基线，处理 1 是完整标称性能门控控制器。双方潜在结果来自同
初态、同实际参数与创新序列的完整已归档仿真。这是从配对表模拟随机日志，**没有新增
随机化实车或 SUMO 执行**。处理选择在回合开始前作出，部署时不做逐步 CSPI 切换。

三个固定模型 1802、1812、1822 全部保留，使用相同的初态/动力学选择、处理分配和
数据拆分，分别运行统计流程；不能将它们合并当成 480 个独立样本或只选最佳模型。
CSPI 的部署决策范围与在线逐步门控不同，结果必须以“回合级策略选择”命名。

输入只包含重置时三车位置/速度和已声明动力学类别的 one-hot 编码，不使用真实随机
增益、阻力、滞后参数、未来创新、最终损害标签或配对反事实结果作为策略特征。
学习/选择函数只接收随机分配分支的负团队成本，倾向概率固定为 0.5。

## 四份数据和固定配置

用同一 RNG 的固定排列将 160 个初态拆成 64 拟合、32 调优、32 安全测试、32 最终
评估。只在拟合组的观察分支训练两个 Ridge(alpha=1) 结果模型；标准化器也只拟合
该组。结果模型差作为处理效应评分；候选阈值固定为拟合组评分的 0.1/0.3/0.5/0.7/0.9
分位数，基线阈值 1e6。评分必须有限且小于该基线阈值，否则接入失败，不更换阈值。
拟合组每个处理臂至少八个样本；不满足时保留失败，不重抽分配。

调优、安全测试与评估组完全不参与结果模型拟合或候选阈值生成。这是为交通任务提供
独立预训练评分，不照搬作者合成驱动的全样本辅助模型交叉拟合；这项改动明确披露。
保留原函数体：PDE、cutoff_selection、safety_test_single、safety_test 以及其依赖函数。
源文件仍为作者提交 `b5af605a38a7866c52745c153e02cb4bf049ea01` 的固定 Git blob
`84323a8cf90351cf69fbbc59300523ddca54f625`，第三方源码不重新发布。

运行原 CSPI（DR expected improvement 单阈值）与 CSPI-MT（最大通过概率起点的多
阈值）两种规则。误差参数 0.05，10000 次高斯模拟，test_ratio=1；选择 RNG seed
为 804620+模型序号，MT 测试 seed 为 804630+模型序号。多个阈值通过时，按作者
驱动在调优与测试合并观察数据上的价值估计选取通过者；无人通过时采用完整基线。
最终评估组不进入此选择。原 HCPI 的硬编码结果范围常数不直接迁移到交通奖励。

用独立指示函数差乘以 DR 分数，核对原 PDE 对全部候选的均值与协方差。调优或测试
评分若恰好等于候选或基线阈值，保留端点失败而不是抖动/删样本。若候选重复、任一
候选方差为零或估计非有限，则该模型开发接入记为不可检验，回退基线，不伪装成通过。
固定选择一次，不按结果重抽种子、加大样本或更改候选。

## 输出和解释

保存固定分配、拆分、每模型随机日志、辅助模型参数、阈值、作者选择/测试输出和
最终评估。两个处理臂的反事实成本仅在事后审计文件和最终评估使用；原作者函数
获得的 DataFrame 不含另一分支结果。评估另报同一批条件上的 always-baseline、
always-nominal 和 always-bank。这里的 always 表示选用完整控制器，不代表每步采用 RL。

逐项分开统计“选择学习控制器的回合”与“实际执行学习指令的回合”。损害、失败、
收益使用原 V36 定义，不因 CSPI 仅针对期望收益而删除个别车辆退化。任一配对失败
保留并使全范围收益不可评估；当前输入中基线和两种性能控制器均已完成。

32 个安全测试回合只能提供小规模接入证据。原高斯近似不因此获得有限样本有效性；
均值改善检验不是采用条件下的逐车损害概率界或物理安全证明。旧场景固定分层及
此前已知的总体效果也限制了推断解释。所有原始选择通过/失败都报告，但不宣布新认证。
正式公平结论仍需独立随机初态、足量日志、匹配训练/评估预算和单独冻结的执行计划。
