# 单窗口滞后与持续偏差的条件可辨识性

本结论解释观测历史门控的物理信息来源。它是已声明执行器模型的递推性质，
不声称新的系统辨识定理，也不推出当前完整门控已经保证未来性能。

考虑单车、单位增益、零阻力，物理步长0.1s，一个控制窗口包含五步，固定指令u：

\[
m_s=\rho^s m_0+(1-\rho^s)u,\qquad
v_s=v_{s-1}+0.1(m_s+b),\qquad p_s=p_{s-1}+0.1v_s.
\]

假设这五步速度不裁剪、创新b在窗口内为常数，初始记忆m₀已知。定义观测组合

\[
Z=(p_5-p_0)-0.5v_0-0.3(v_5-v_0)
  =p_5-p_0-0.2v_0-0.3v_5.
\]

将速度和位置递推相减，偏差b精确消去，得到

\[
Z=0.01(m_0-u)\phi(\rho),\quad
\phi(r)=2r+r^2-r^4-2r^5
=r(1-r)(2+3r+3r^2+2r^3).
\]

证明：位置增量为0.5v₀+0.01∑(6−s)mₛ+0.15b，速度增量为
0.1∑mₛ+0.5b，因此Z=0.01∑(3−s)mₛ。常数指令项的系数和为零，
记忆差项的系数依次为2、1、0、−1、−2，即上式。

当m₀≠u时，只要φ在声明区间严格单调，Z即可唯一确定ρ。然后由

\[
b=2(v_5-v_0)-0.2\sum_{s=1}^5m_s
\]

唯一确定窗口内的常数偏差。首次控制窗口的m₀=0由实验复位契约给出，
非零u即可提供所需激励；后续窗口的记忆不能无条件视为已知。

本项目的两种滞后类别恰好各位于单调区间：

- 轻度滞后ρ∈[exp(−0.1/0.03),exp(−0.1/0.05)]，约[0.03567,0.13534]。
  φ′(r)=2+2r−4r³−10r⁴在整个区间为正；保守下界
  2−4r_hi³−10r_hi⁴大于1.98。
- 强滞后ρ∈[exp(−0.1/0.3),exp(−0.1/0.5)]，约[0.71653,0.81873]。
  φ′在整个区间为负；保守上界2+2r_hi−4r_lo³−10r_lo⁴小于−0.47。

设初末位置测量误差分别不超过ε_p，初末速度误差分别不超过ε_v，且指令及
已知m₀准确，则|Ẑ−Z|≤2ε_p+0.5ε_v。在同一单调区间内，若两者均满足
模型方程，可由中值定理得到确定性灵敏度界

\[
|\hat\rho-\rho|\le
\frac{2\epsilon_p+0.5\epsilon_v}
 {0.01|m_0-u|\inf_{r\in I}|\phi'(r)|}.
\]

该式展示激励不足时辨识变差，并说明位置与速度联合观测为什么比单独速度
多提供一个能消除持续偏差的方程。若m₀存在误差，还必须另外传播其影响，
不能照用本界。当前仿真未引入传感器误差，实际车载精度仍需单独建模。

当前实现使用多窗口有界最小二乘、65点网格与局部求精，不是上述逆方程的
经过区间验证的求根器；有限数值精度和全局求解能力没有由该唯一性结论自动保证。
未来扰动若为uniform或pulse，历史窗口拟合到的b不等于未来b；上述识别结论也
不会替代未来扰动覆盖。速度裁剪、非单位增益、非零阻力、复位之前未观测到的
记忆都超出该推导。当前门控在未辨识时还可能采用有限预测获准的动作，因此
不能将本条件结论扩展成整回合逐车性能保证。它支撑预测见证的构造；最终
采用后风险、采用率和收益仍必须通过新的独立完整闭环实验检验。
